看点What to notice
  • ②里音频每 1 秒编码成 13 个 token 写进 KV——用户闭嘴那一刻，整句话已经在模型"眼前"了，不用再补录音处理。 In ②, each second of audio becomes 13 tokens written into the KV cache — when the user stops, the whole utterance is already "in front of" the model.
  • 灰色"投机检索"在说话期间只做不提交：KV 是只能追加不能涂改的，工具清单必须等判停后一次性注入（晚注入）。 Grey "speculative RAG" runs during speech but commits nothing: a KV cache is append-only, so the tool list is injected once, after end-of-turn (late injection).
  • 首字时延差距（绿色标记）就来自省掉的整段音频 prefill。 The first-token latency gap (green markers) comes from skipping the whole-utterance audio prefill.
