每日调研日报 · 2026-08-07

KV 恢复：RestoreKV（当前 B 版持久 KV 曾损失约22个百分点，但 KV 更新本身不是110ms/token主瓶颈；论文在固定总预算内用一次 LoRA 恢复前向生成八个恢复 token，Qwen3-4B 的5% KVzip RULER-4K由38.2升至73.2；可以尝试训练 Qwen3-Omni 专用 adapter 做离线同预算 A/B，但不能外推为 MoE 加速）

KV 诊断：Sparse Event-KV（当前删除旧音频 KV 后仍可能存在 context attraction；论文用 donor-pair 证明下游 KV 会保留已删除源事件的二元语义，但四分类、八分类和数字载荷迅速失效；可以固定服务 KV、工具和 query，只翻转被删音频中的车态/席位值，检查输出是否仍随隐藏 donor 翻转）

工具证据：LedgerMind（当前工具名、参数、执行接受、最终车态和口播还需统一证据契约；论文用结构化账本、实体/数字一致性和有限类型修复约束后续声明只能引用工具来源；可以把 source/version/active/cited 加入 VAmoS/MIST 证据链，但 provenance 不能替代 CarSim 真值）

轨迹评测：Silent Failures（当前最终答案或车态正确可能掩盖错误乘员、伪工具证据和错误相消；论文中四个模型的 Trajectory-Correct Rate 均低于表面准确率，细粒度标签的跨裁判一致性又很弱；可以同时报告 outcome、trajectory 和 timing，并用确定性断言覆盖安全桶）

Agent Harness：OneDayAgent（当前 endpoint 后的复杂任务缺少全局产物验证和定点修复；论文中 verification-only 将104项得分由0.771升至0.804、平均耗时由27.6增至29.7分钟，FULL 则增至53.6分钟；可以先只移植执行后验证，不启用任意 shell 或完整小时级流程）

多模态忠实度：OPPO（当前回答可能忽略音频/视觉或根据另一模态编造证据；论文通过单模态遮蔽和证据 token 定向 KL 提升音频/视觉遮蔽指标；可以先做无需训练的音频、嘴部、屏幕和工具遮蔽回归，检查车控是否真的依赖对应来源）

音视频评测：AVSCap（当前音视频理解不能只看视觉字幕加 ASR；论文将 Speech、SFX、Music 与视觉事件按时间绑定，Synergy Recall 为57.70%、对照为29.13%；可以把座舱事件拆成语音、非语音声、视觉和工具时间绑定，但它不是流式判停或原生全双工）

记忆准入：FocusMem + SpatialSTALE（当前晚到工具和长期记忆可能无关或过期；前者用动态读出和相关性门，后者显示未过滤旧记忆可显著提高下游死亡率，但检测陈旧不等于动作正确；可以在影响 token/TTS 前记录来源、版本、相关性和陈旧度，短期使用结构化门而非 latent memory）

多语 ASR：LS-MOPD（当前 ASR micro CER 为6.39%，但与外部混合指标不可直接比较；论文共享冻结声学前缀的三教师蒸馏将 streaming 平均错误率由5.74%降至5.18%；基座、代码和权重均未开放，暂作长期训练参考，不进入实现队列）

AEC/判停/空间听觉：无重大新增（今日没有经正文核验的 AEC、中文语义判停或 FOA 新结果；继续 NAC + label-delay、QIANGDA 成对身份和独立播放参考测试，SpatialSTALE 是空间记忆而非空间音频）

全双工/TTS/实时服务：无重大新增（今日没有开放度和证据超过 Lychee-FD 的原生全双工后端，也没有直接降低 Edge TTS 约3秒首音频或修复每token约816次 GPU→CPU 同步的新技术；继续 Lychee-FD 离线回放、本地 CosyVoice 首包硬门和无同步 fast path）
