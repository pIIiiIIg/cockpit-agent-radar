推理加速：无同步 MoE fast path（当前 Qwen3-Omni 解码约 110ms/token，项目剖析指向 HF MoE 每 token 约 816 次 GPU→CPU 同步；以 index_select+bmm 消除逐专家同步；准备在 5090/H200 上对比原实现与 monkeypatch 的 ms/token 和输出一致性，今日 Radar 没有可直接核验的内核候选）

工具/Action 通道：Qwen-UI-Agent（当前候选门已拦住约45%的候选外工具失配，但仍有52组近义工具和聚合意图展开不全；用 typed Action batch、候选内判据、权限/前置条件/幂等门和最终车态验证约束执行；准备做400条“参数+最终车态”回归并单列聚合意图完整率）

多乘员响应决策：Cocktail-Talker（当前车内语音可能对助手、其他乘员或与助手无关；论文用 RESPOND/LISTEN/IGNORE 显式动作区分，在合成多人噪声测试中 Respond/Silent macro-F1 为0.930，但不是流式判停器；准备把三动作标签迁移到真实座舱多座位回放，作为 FastTurn/SoulX 之后的受话对象门）

TTS 忠实度：ECCD（当前本地自回归 TTS 仍需防错读、漏读和重复；ECCD 用同一语音 LM 的有文本/无文本双分支增强正向对齐，CosyVoice2 英文 WER 由2.98%降至2.08%，但论文未报告双分支时延；准备在 CosyVoice2/3 上联合比较 CER、首音频 P50/P95、RTF 和显存）

语音表达评测：SpeechParaling-Bench（当前评测偏文本正确率，缺少语气、音量渐变和情境适配；该基准用1,001个中英样本覆盖13个维度，动态变化是受测模型最弱任务；准备加入儿童安抚、驾驶告警、导航播报等回归，同时保留首包和打断硬门）

流式视觉 Agent：StreamingClaw v2（当前长视频、记忆、主动触发和工具闭环彼此分散；该框架组合滑窗 KV、层次事件记忆、主动 trigger 与 vehicle skills，但正文没有准确率、硬件、吞吐或延迟；准备只复用接口思想做最小原型，先测事件误报/漏报、KV增长和工具闭环）

长音视频理解：Audio-Visual Flamingo（当前座舱音频和视频常被分开理解；AVF 按时间交错音视觉 token 并用时间戳推理链处理最长15分钟输入，但没有在线流式输入或推理时延且官方权重为非商用许可证；准备仅用作离线教师和联合证据评测，不进入量产主链）

AEC、空间听觉与 KV cache：沿用前一日已核验路线（今日无重大新增；继续采用 AEC/LMPAN→因果 NS→判停、空间座位线索与有界 KV 的问题分层；准备继续真实双讲、M3 多轮打断和长会话 KV 裁剪回归）
