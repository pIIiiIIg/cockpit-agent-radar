每日调研日报 · 2026-08-04

  • 多乘员响应决策：Cocktail-Talker

    • 当前问题是车内语音可能对助手、其他乘员或与助手无关。论文用 RESPOND/LISTEN/IGNORE 三个动作区分，并在合成多人噪声测试中把 Respond/Silent macro-F1 做到0.930；但它依赖固定话轮边界，不是流式判停器。可以尝试把三动作标签迁移到真实座舱回放，作为 FastTurn/SoulX 之后的受话对象门。

  • TTS 忠实度：ECCD

    • 当前自回归 TTS 仍会错读、漏读和重复。ECCD以同一语音 LM 的有文本/无文本双分支做正向对齐增强，SeedTTS-Eval 的12个模型/子集组合均改善；例如 CosyVoice2 英文 WER 2.98%→2.08%。可以在本地 CosyVoice 上 A/B，但论文没有报告双分支的首包延迟和 RTF。

  • 语音表达评测：SpeechParaling-Bench

    • 当前评测偏文本正确率，缺少语气、音量渐变和情境适配。该基准含1,001个中英样本和13个维度；动态变化是受测模型最弱任务。可以加入儿童安抚、驾驶告警、导航播报等回归，但不能替代流式打断和时延评测。

  • 工具/Action 通道：Qwen-UI-Agent

    • 当前 Harness 需要比自由 JSON 更明确的执行协议。论文统一 GUI/CLI/API 动作，支持 ordered batch、ask_user、持久事项和执行后验证。可以借鉴为 typed Action batch + 权限/前置条件/幂等门；其主动服务只有案例，没有座舱成功率或时延结果。

  • 流式视觉 Agent：StreamingClaw v2

    • 当前长视频、记忆、主动触发和工具闭环彼此分散。该框架组合滑窗 KV、层次事件记忆、主动 trigger 与 vehicle skills；但正文没有数据集、准确率、硬件、吞吐或延迟，不能视为“已验证实时”。可以先复用接口思想，不直接选型。

  • 长音视频理解：Audio-Visual Flamingo

    • 当前座舱音频和视频常被分开理解。AVF按时间交错音视觉 token，并用时间戳推理链处理最长15分钟输入；Video-MME 为70.7/71.2，但 LongVideoBench 低于 OmniVinci，且没有在线流式输入或推理时延。官方权重是非商用许可证，适合离线评测/教师，不宜进入量产主链。

  • AEC、空间听觉与 KV cache

    • 今日无重大新增。继续跟踪 AEC/LMPAN+因果 NS 的真实双讲数据、M3 多轮判停/打断、空间座位线索、Harness C 并行 RAG 约束、本地 TTS 首包和长对话 KV 裁剪。
