From Pixels to PCells: A Neurosymbolic Approach to Photonic Component Creation

论文Paper · arxiv · 2026-07-29 · ◈ 5
摘要Summary
PixCell 把静态器件轮廓转换为受限 DSL 的参数程序，并用确定性执行与 IoU 验证驱动修订，最佳 Agent 配置平均 IoU 达 0.974。对 Harness 的价值是 typed 工具和最终状态验证闭环，而非流式语音、判停或 TTS。 We present PixCell, a neurosymbolic system in which multimodal agents convert a visually presented photonic component into a parametric program over a small domain-specific language (DSL) of geometric primitives. A system enabling deterministic visual verification renders evaluation asymmetrically cheaper than the generation attempt. While models using multi-seed sampling and iterative revision reach a mean best-turn IoU of only 0.416, multimodal agents through PixCell's interface and verifier consistently exceed 0.9 mean IoU, with scores reaching 0.974 and 0.955 across eight component targets while also satisfying source contracts. These results demonstrate that frontier multimodal agents can reliably understand and render executable parametric representations from visual targets. Using these live parameters, cross-stack studies on an interferometer reconstruct primitive programs that satisfy an 8.0 nm free spectral range target and the original footprint constraint on modeled 220-nm SOI, 400-nm SiN, and 400-nm TFLN stacks. PixCell further carries a paper-derived splitter from visual reconstruction through SOI full-wave simulation, producing symmetric propagation and balanced outputs. Finally, the same executable verifier supplies a training reward and dataset used to train a Qwen3.6-35B-A3B model with LoRA and GRPO without supervised demonstrations. On eight training-excluded paper figures, its mean champion IoU rises from 0.422 after eight initial attempts to 0.491 after three verifier-guided revision rounds. These results therefore establish a controlled framework for measuring, retargeting, and improving visual-to-parametric photonic component design.

深度讲解Deep dive

PixCell 把光子器件轮廓转换为受限 GDSFactory DSL 的可执行参数程序，并用确定性渲染验证器驱动多轮修订。

它解决什么问题Problem

像素描摹不能保留可编辑参数，预制 PCell 又局限于作者预设空间；目标是从图像恢复可执行、可审计且尺寸可独立修改的参数化器件表示。

核心方法Core method

PixCell 接收二值轮廓和物理尺寸，让多模态 Agent 在禁止原始多边形和未许可预制器件的受限 DSL 中生成 Python 程序。验证器固定像素/微米标定，执行、栅格化并计算 IoU 和源码合规性；候选可经外部 harness 或编码 Agent 反复修订，之后再进入分层物理仿真。验证器还被用作 GRPO 奖励训练 LoRA。

怎么工作How it works

  1. 提取目标轮廓与物理 footprint 并冻结标定。
  2. Agent 用许可几何原语生成参数化程序。
  3. 执行程序并计算 IoU、边界残差和源码合规性。
  4. 根据差异反馈选择并修订候选。
  5. 对活参数做跨材料栈重定向或分层物理验证。

论文报告了什么Reported findings

  • 26 个配置在 8 个目标上生成 208 个程序，最高平均 IoU 为 0.974，第二名为 0.955，且均通过源码门。
  • 640 条普通修订轨迹的首轮平均 IoU 为 0.369，最佳轮平均仅 0.416；训练后策略经三轮验证反馈的 champion 平均为 0.491。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 可把受限 DSL 映射为 typed 车控工具，把几何验证器映射为前置条件、幂等性和最终车态验证，形成候选—执行—反馈闭环。
  • 论文输入是静态图像且反馈发生在轮次间，不支持音频判停、解码中异步注入或 TTS；验证循环应保护实际动作而非阻塞口播。

边界与局限Limits

  • 仅八个合成单层目标，每个配置—目标只运行一次；IoU 只验证二维几何，不证明参数独立性或器件功能。
  • 物理模型和 foundry 规则不完整，方向耦合器的简化估算对全波结果高估 5.5 倍，最终未见表示探针也全部失败。
