Compute Globally, Materialize Locally: The Memory Contract of Sparse Event-KV

论文Paper · hf · 2026-07-25 · ◈ 5
摘要Summary
Sparse Event-KV 用 donor-pair 证明下游 KV 能继续携带已删除源事件的紧凑语义状态，但写入依赖措辞、模型和位置，载荷扩大后迅速失效。对 Harness 最重要的是：删掉音频源 KV 不等于清除其影响，应固定已服务 KV/工具/query、只翻转被删音频状态来诊断 context attraction。 Long-horizon agents increasingly reuse their KV cache as memory: a serving system keeps a subset of cached entries and drops the rest. Eviction and episodic-memory schemes therefore rest on a premise rarely tested directly, that a retained event is still informative once the observations that produced it are gone. We test it by omitting one earlier observation from what is served, across otherwise identical agent histories. Among items sensitive to that observation, the answer overwhelmingly follows the omitted value, though no served span says which value is correct. We call this semantic materialization: a downstream event's cached rows act as an independently servable view of computation whose inputs are gone. It can also be written on purpose. A deliberately phrased, answer-free event raises donor-aligned recovery from 6% to 51% on Qwen3-8B without ever naming the value, whereas passively harvesting natural mentions from long-term dialog yields no detected advantage. What such a row carries is specific and bounded. Compact state survives, larger payloads decay toward chance, and whether a construction writes at all turns on phrasing rather than on meaning alone, so two phrasings the model comprehends equally well can diverge sharply. The result is a memory contract for sparse event-KV serving: what to write, where it lands, and what survives once the source is gone. For anyone who evicts the corollary is that dropping a source event and observing no accuracy loss does not show the source was unnecessary.

深度讲解Deep dive

Sparse Event-KV 证明：下游事件 KV 可以保留已删除上游事件计算出的紧凑语义状态，但这种“语义物化”高度依赖措辞、模型、服务位置和载荷大小。

它解决什么问题Problem

稀疏 event-KV 系统常删除原始观察、只保留下游事件；论文检验被保留行究竟只表示可见文本，还是已经写入来自被删除源事件的计算结果。

核心方法Core method

系统先对完整轨迹做全局 prefill，再按 event 切分 KV block，服务时选择少量 block、保留原位置/RoPE 并删除源事件。donor-pair 构造让两条轨迹的已服务 token、位置和 decoy 完全相同，唯一差别是已删除源值；若输出随隐藏 donor 翻转，即证明保留 KV 存在因果信息。实验冻结模型并用 root、reference edge、carrier、独立重编码、菜单/logit readout 等控制，把 memory contract 拆成 Trigger、Landing、Access 三层。

怎么工作How it works

  1. 全局 prefill 含源事件、root/载体和后续引用的完整轨迹。
  2. 服务时删除源事件，只选择 root、carrier、edge 与固定 scaffolding。
  3. 在未来 query 未参与写入的条件下，按原位置追加并读出 query。
  4. 对 donor pair 统计 follow/anti/const，并按 checkpoint 校准措辞、serve set 和 readout。

论文报告了什么Reported findings

  • Qwen3-8B root-only 的 donor-sensitive 输出 follow:anti 为 99:0，p=3.2×10⁻³⁰；256-pair 复现为 130 follow、0 anti、125 const。
  • 16 种构造的完整文本理解均值为 .98、最低 .77，但写入率从接近 chance 到 .95；不同模型的可写构造差异显著。
  • Gemma-4 中，经 edge 询问时 root donor 为 41:0；只服务 edge 时仅 2:0，说明 edge 主要路由回 root。
  • Qwen3 恢复率随载荷扩大迅速下降：二元状态 .934、四分类 .223、八分类 .156，三位数精确恢复为 0/192。
  • Qwen3 的主动 carrier 从 passive mention 的 11/192 提升到 NL compute directive 的 97/192；真实 LoCoMo 被动 harvest 则为 -0.044。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：它与 context attraction 直接相关；即使音频源行被删，下游 B-path 行仍可能携带其语义状态，“删源后准确率不降”不能证明源未被使用。
  • 编辑判断：可采用 donor-pair 诊断，只翻转被删除音频中的状态，固定已服务 KV 位置、晚注入工具和 query，测试回答是否仍随隐藏 donor 翻转。
  • 编辑判断：校准 carrier 最多适合少量二元/枚举状态，不适合丰富语音、数字或完整工具载荷；该机制也不解决 110 ms/token 的 MoE 同步。

边界与局限Limits

  • 它只是紧凑状态通道：字符串逐字转移仅 9.7%，较大分类和数字载荷接近失败。
  • 没有通用 carrier 语法；写入和读出依赖 checkpoint、表述、query 形式、绝对位置和共服务行。
  • 真实对话被动物化没有显示收益；主动正结果主要来自合成 donor-pair，且 hybrid/linear-attention 模型未必支持逐 token KV 服务。
