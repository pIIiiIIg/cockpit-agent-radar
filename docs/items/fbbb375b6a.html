EchoChain: A Full-Duplex Benchmark for State-Update Reasoning Under Interruptions

论文Paper · arxiv · 2026-04-08 · ◈ 19
摘要Summary
EchoChain 是一个受控基准，专门评估全双工语音助手在用户中途打断后能否正确更新任务状态并继续对话，并归纳出打断后续回复中的三类典型失败模式。它命中现有轮次式评测覆盖不到的盲区，可作为本站座舱助手打断恢复（barge-in 后状态修正）能力的回归测试与选型依据。 Real-time voice assistants must revise task state when users interrupt mid-response, but existing spoken-dialog benchmarks largely evaluate turn-based interaction and miss this failure mode. We introduce EchoChain, a controlled benchmark for evaluating full-duplex state-update reasoning under mid-speech interruptions. 深度讲解Deep dive

EchoChain 是检查语音助手被中途打断后能否更新任务状态、又不丢失原目标的受控评测。

它解决什么问题Problem

普通语音评测只看最终答案或打断速度，无法发现助手听见改口却继续旧计划、短暂更新后又忘记等状态推理错误。

核心方法Core method

基准用场景驱动对话，在相对助手开口的固定时刻注入与上下文相关的打断，再检查后续回答是否同时保留原任务和新增约束。

怎么工作How it works

  1. 建立含明确任务状态和约束的对话场景。
  2. 助手播报期间按统一时间注入用户改口。
  3. 比较打断前后状态，分类上下文惯性、打断遗忘和目标丢失。

论文报告了什么Reported findings

  • 论文评测的实时语音模型没有一个通过率超过 50%。
  • 改为半双工对照后，总失败相对下降 40.2%，说明大量错误确由中途状态更新造成。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 可直接改造成车控回归：机场改火车站、空调改车窗、执行中撤销和后续指代。
  • 测试必须记录计划、下发、执行、撤销和补偿，而不仅是口播文本。
