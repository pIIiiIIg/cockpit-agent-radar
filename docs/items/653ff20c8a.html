深度讲解Deep dive

该工作用 GRPO 分别优化原生双音频流模型的停顿、接话、附和和用户打断，并叠加语义奖励，避免只追求低延迟而损伤回答内容。

它解决什么问题Problem

逐 token 的监督学习不直接优化何时说、何时沉默和何时让权；现有强化学习又常只处理单一行为，出现时序变快但语义质量下降。

核心方法Core method

论文从 Fisher 和 Seamless 双声道语料按 pause、turn、backchannel、interruption 四类事件抽取短片段。每片段由 Moshi 或 PersonaPlex 采样 16 个完成，分别计算沉默违规、负响应延迟、附和位置 F1 和打断延迟；接话与打断再加入 Qwen3-235B-A22B 语义奖励，以 clipped GRPO 和 KL 约束更新并行文本控制流。

怎么工作How it works

  1. 对双声道人类对话执行 VAD，并按四类交互规则抽取片段。
  2. 随机附加最多 30 秒前置上下文，为每片段采样 16 个完成。
  3. 计算轴特定时序奖励，接话与打断再加入语义自然度奖励。
  4. 组内归一化优势，只更新文本控制 token，并以冻结参考模型做 KL 约束。

对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：四轴事件定义和“时序+语义”组合奖励可直接用于 Harness 的 endpoint、打断取消、首音频和 TTS 停声回归。
  • 编辑判断：论文模型在统一时间轴同时处理用户与助手音频；当前 Harness 是流式输入、判停后生成、晚注入工具和外挂 TTS，不能称为原生全双工。

边界与局限Limits

  • 奖励依赖人工规则，且训练目标要求模型具有并行文本控制流。
  • 没有真人交互评价；动态评测还因 GPT-Realtime 的 VAD 行为限制被测模型音频，不能视为完全无约束双工。
  • 训练语料会改变安全行为；正文与附录对 LLM 奖励量表还存在 1–3 与 0–2 的不一致。
