GDPevo: Evaluating Agent Self-Evolution on Real Business Tasks

论文Paper · hf · 2026-08-03 · ◈ 4
摘要Summary
GDPevo 用规则杂交把企业内部规则分散到训练任务并组合进留出任务，使“从经验学习”成为可归因、可确定性评分的能力。现有 Agent 能提高准确率和部分执行效率，但最佳结果仍远低于全信息条件，跨域技能还可能负迁移。 Agent self-evolution updates an agent's persistent state from prior experience and reuses it to solve related tasks more effectively. Evaluating self-evolution is difficult: existing benchmarks provide limited coverage of economically valuable task domains, do not always design training and test tasks such that test-time gains can be attributed to training experience, and remain vulnerable to data contamination. We present GDPevo, an evolution-native benchmark grounded in GDP-related enterprise workflows, together with the fully automated data pipeline that generates it. Its core mechanism, rule hybridization, decomposes each enterprise workflow into atomic business rules, distributes subsets of these rules across training tasks, and recombines them in held-out test tasks so that test-time gains are attributable. GDPevo spans CRM, ERP, finance, healthcare, legal, and data-centric workflows. Its V1 release contains 120 tasks in 12 groups, with five training and five held-out test tasks per group. Full automation enables the pipeline to expand the suite to 240 tasks in 24 groups (V2) within two days, providing a practical response to contamination. Using GDPevo, we evaluate four agents, each comprising a harness and a model, under four supervision types. Self-evolution consistently improves held-out accuracy by up to 16.44 percentage points. But the best evolved agents remain far below the fully informed oracle ceiling of 91.6%, indicating that the self-evolution ability of current agents remains far from fully realized. We publicly release the pipeline, benchmark, and full evaluation results at https://github.com/Prism-Shadow/GDPevo.

深度讲解Deep dive

GDPevo 通过“规则杂交”构造企业任务的训练—测试关系，检验 Agent 能否把先前经验沉淀为持久技能并组合迁移到新任务。

它解决什么问题Problem

既有自进化评测缺少高价值企业任务、训练经验与测试增益之间的可归因关系，也容易受到公开静态题集污染。

核心方法Core method

系统把企业流程拆成原子隐藏规则，将规则分散到训练任务并在测试任务重新组合；确定性规则评分器再在 base、fewshot、self、reflect-3 四种条件下比较四组 harness+model Agent。

怎么工作How it works

  1. 从 GDPval、SOP-Bench、JobBench 等抽取种子场景。
  2. 自动生成共享环境及每组 5 个训练、5 个测试任务，并实施规则杂交。
  3. 校准基础难度与进化增益，交给 6 个独立 Reviewer Agent 审核，至少 5 票通过。
  4. 以 base、fewshot、self 或 reflect-3 生成或不生成 SKILL.md。
  5. 在隔离容器中重复测试三次，统计规则准确率、轮次、token 和成本。

论文报告了什么Reported findings

  • Opus-4.8/Claude Code 从 50.63% 提升至 67.07%，即最高增加 16.44 个百分点；所有进化组合增益为 2.59–16.44 个百分点。
  • GPT-5.5 fewshot 提升 15.14 个百分点，同时测试成本下降 20.88%；计入一次性技能成本后约为 1.296 美元/任务，接近 base 的 1.294 美元。
  • 全信息 human+Codex 条件达到 91.6%，仍显著高于最佳进化 Agent 的 67.07%。
  • 跨域 fewshot 的 6 个非对角迁移中 5 个为负、最差为 −5.0 个百分点；reflect 一半为正、最好为 +6.5、最差仅 −1.0 个百分点。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 可用于评测“commit 后演化”：把一次已提交请求、执行轨迹和迟到工具结果视为完整 episode，再生成技能供下一次提交使用。
  • “Agent=harness+model”及成本指标适合比较 StreamingModelHarness 的上下文、技能加载和工具注入策略。
  • 论文是离散任务/反馈循环，与流式输入、外置 TTS 或模型级并发听说无关。

边界与局限Limits

  • 实验只验证文本技能演化，没有实测参数、代码、工作流或其他持久状态更新。
  • 任务生成、校准和审查主要使用同一 Codex/GPT-5.5 系列，可能留下生成模型偏置。
  • 91.6% 是非专家人工操作员配合 Codex 的全信息条件，不是真正领域专家上界。
  • 跨域实验只选 CRM、ERP、Finance 各一个 V1 任务组。
