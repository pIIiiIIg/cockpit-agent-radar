BayLing-Duplex: Native Full-Duplex Speech Dialogue with a Single Autoregressive LLM

论文Paper · arxiv · 2026-06-12 · ◈ 26
摘要Summary
BayLing-Duplex 用单个自回归 LLM 实现原生全双工语音对话，摆脱 LLaMA-Omni、GLM-4-Voice 等轮次式方案对外部 VAD 判断用户话轮结束的依赖，原生处理重叠、犹豫与 barge-in。单模型架构与站内"流式进 KV、边说边听"的 harness 设计高度同构，是验证单模型路线可行性与去 VAD 化的重要参照。 Real-time, full-duplex speech interaction is a key feature of next-generation spoken chatbots, allowing the model to listen and speak at the same time and to handle natural phenomena such as overlap, hesitation, and barge-in. 深度讲解Deep dive

BayLing-Duplex 用一个约 9B 自回归 LLM 同时建模用户语音、助手文本和助手语音，让开口、沉默与打断都变成 next-token prediction。

它解决什么问题Problem

传统语音助手依赖外部 VAD 和轮次控制器，难以自然处理重叠说话、犹豫与用户打断；多个控制模块也会增加时序复杂度。

核心方法Core method

模型基于 GLM-4-Voice，将用户语音、助手文本和助手语音按块交错到一个多通道序列中，并加入 SILENCE、assistant、PAD、EPAD 等状态 token。模型通过 SFT 学习序列布局，再用 DPO 优化开口和打断时机。

怎么工作How it works

  1. 语音 tokenizer 将连续用户音频离散化。
  2. 单个 LLM 联合预测对话状态、助手文本和语音 token。
  3. 状态 token 决定继续沉默、开始回答或停止当前语音。
  4. 语音 decoder 将预测 token 还原为声音。

论文报告了什么Reported findings

  • 论文报告 InstructS2S-Eval 轮次切换成功率 92%，打断成功率 100%。
  • Llama Questions 准确率 46.0%，高于论文中 Moshi 的 21.0%。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 适合作为原生全双工语音基线，并借鉴状态 token 与交互 DPO 的训练目标。
  • 不宜直接替换 Qwen3-Omni：它没有视觉输入，也未证明适应车内噪声、多乘员和车控安全。

边界与局限Limits

  • 模型卡明确表示主要在合成近场语音上评估，未覆盖多方对话、情绪轮替和复杂噪声。
  • 基于 GLM-4-Voice 自定义许可，商业使用需要登记并遵守标注要求。
