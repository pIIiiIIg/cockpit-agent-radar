摘要Summary
一个用 Rust 为 Node.js 提供原生语音智能体能力的库，内置 WebRTC、VAD、barge-in(打断)和语音事件，并通过 Sherpa-ONNX 提供免费的端侧 STT/TTS，LLM 逻辑留在 TypeScript 侧。对座舱助手很有参考价值：打断检测与 VAD 是全双工"边说边听"的关键痛点，端侧 STT/TTS 契合车内低延迟与隐私需求，其"推理引擎与 LLM 解耦"的分层也与自研 harness + 外挂 TTS 的架构思路一致。 Rust-native voice agents for Node.js — WebRTC, VAD, barge-in, and speech events. Free on-device STT+TTS via Sherpa-ONNX; cloud vendors optional.
