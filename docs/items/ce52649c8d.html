Extracting Voice Styles from Frozen TTS Models via Gradient-Based Inverse Optimization

论文Paper · arxiv · 2026-07-28 · ◈ 7
摘要Summary
冻结 SupertonicTTS 与 WavLM、只优化 timbre style，即可从一段无转录录音恢复可用声音 JSON；154 人上 ECAPA 相似度由 0.132 升至 0.413，但 WER 上升且代码缺正式许可证。它适合离线声音注册，不改善 StreamingModelHarness 的流式 TTFA，并需按高风险声音克隆能力治理。 Some text-to-speech systems ship a synthesis model and preset style vectors but not the reference encoder that turns audio into such a vector. The model still accepts a style vector; a user with a voice of their own cannot produce one. We solve for that input directly, inverting the released pipeline by gradient descent: every weight stays frozen and only the style vector is optimized, against time-pooled WavLM statistics of one recording. Because the objective discards the time axis, the synthesized text may differ from the recording, so no transcript and no alignment are needed. On 154 speakers from two corpora, ECAPA-TDNN similarity rises from 0.132 to 0.413 and ResNet from 0.099 to 0.401, improving for every speaker; a verifier at its equal-error point accepts 53% of the recovered voices as the target, against 1% for the presets they start from.

深度讲解Deep dive

该方法冻结 SupertonicTTS 和 WavLM，不需要参考编码器、转录或对齐，只反向优化 12,800 维 timbre style 输入，使合成语音与目标录音的 WavLM layer-4 时间池化统计接近。

它解决什么问题Problem

部分 TTS 只发布合成 ONNX 与预设 style vectors，却保留从音频提取 style 的编码器；用户即使拥有目标录音，也无法生成该模型可接受的新 voice style。

核心方法Core method

作者把四个推理 ONNX 图转为可微 PyTorch，只优化 50×256 的 style_ttl，固定 8×16 的时长 style。生成和目标音频进入 WavLM-Large layer 4，沿时间计算 1024 维隐藏状态的均值与标准差，并最小化两项 MSE。算法从十个预设中选最近起点，轮换五个覆盖音素的英文 prompt，以 Adam 和梯度裁剪更新；当 loss 达 0.30 时停止，以避免远离训练 style manifold。

怎么工作How it works

  1. 输入一段无需转录的目标 WAV，用十个预设合成首个 prompt 并选择最近起点。
  2. 冻结转换后的 TTS 与 WavLM，轮换五个自选文本生成语音。
  3. 比较生成音频与目标录音的 layer-4 均值/标准差，只更新 style_ttl。
  4. 达到 0.30 阈值后停止并导出 SupertonicTTS 可读取的 style JSON。

论文报告了什么Reported findings

  • 154 人上 ECAPA 相似度从 0.132 升至 0.413，ResNet 从 0.099 升至 0.401，WavLM-SV 从 0.713 升至 0.836；WER 从 1.84% 升至 3.19%。
  • 154/154 人在 ECAPA 和 ResNet 上改善，145/154 人在 WavLM-SV 上改善；独立指标 Wilcoxon 均为 p<10⁻²⁶。
  • WER 中位数为 0，107/154 人无转录错误；UTMOS 为 4.23，对预设为 4.47，但这是预测 MOS 而非真人听测。
  • 六人从 loss 0.30 继续优化到 0.24 时，ECAPA 从 0.498 升至 0.534，WER 却从 1.07% 升至 5.22%，显示相似度与可懂度开始交换。
  • ECAPA verifier 在 EER 0.9%、阈值 0.406 时接受 52.6% 的提取语音和 1.3% 的预设；FAR=0.1% 时仍接受 18.8% 的提取语音。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：可作为本地 TTS 的离线声音注册步骤，导出的 JSON 能驱动 Supertonic 2，有助于替换外部 Edge TTS 并提供个性化声音。
  • 编辑判断：它不改善 streaming TTFA；批量 16 人时每人仍约需 0.49 分钟，且论文没有首包音频、分块声码器或边生成边播放测试。
  • 编辑判断：这属于高风险声音克隆能力，集成前应要求明确同意、记录来源、加入水印，并禁止把声音相似度当作身份认证。

边界与局限Limits

  • 实验只验证 SupertonicTTS，向其他连续 style-conditioned TTS 的迁移尚未证明。
  • 评测文本就是优化使用的五个 prompts，未测未见文本；自然度只用域外 UTMOS，没有真人听测。
  • 时长 style 没有梯度路径，语速继承初始预设；论文也未测试反 spoofing countermeasure。
