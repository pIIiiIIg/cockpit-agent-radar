DataSpace: Benchmarking Data Agents for Verifiable Analytics over Heterogeneous Workspaces

论文Paper · hf · 2026-08-03 · ◈ 7
摘要Summary
DataSpace 用 410 个中英任务和 7439 个异构文件测试数据智能体产出可确定性验证的完整表格；固定 MiMo-V2.5 时，不同 harness 的准确率相差 15.36 个百分点。它适合为 StreamingModelHarness 的晚到工具、类型/schema 一致性和最终产物验证提供压力测试，但不覆盖流式语音或 TTS。 Data agents enable natural-language analytics over organizational workspaces, where relevant evidence may be scattered across databases, structured files, long documents, and multimedia. Existing benchmarks largely isolate structured querying, retrieval, or open-ended analysis, leaving heterogeneous evidence discovery, complete tabular outputs, and deterministic evaluation insufficiently unified. We introduce DataSpace, a benchmark in which data agents produce verifiable tabular results from task-local heterogeneous workspaces. It contains 410 cross-language tasks and 7,439 artifacts totaling 15.01 GB across CSV, JSON, SQLite, Markdown, PDF, and video. DataSpace also served as the official evaluation benchmark for the KDD Cup 2026 Data Agents for Complex Data Analysis competition. Each agent receives only a question and workspace and returns the complete requested tabular result. We construct DataSpace with DataSpace-Builder, an execution-grounded framework comprising cross-language transformation, constraint-aware relational sampling, modality routing and artifact rendering, and human review and task repair by 11 domain experts. A deterministic evaluator performs header-invariant column alignment, type- and precision-aware normalization, and order-aware row comparison. Across six recently released frontier multimodal models and five widely used agent harnesses, the best accuracy reaches 66.34%, while harness choice creates a 15.36-point spread with the backbone fixed. Multimodal evidence integration and joins consistently reduce accuracy across all six backbones. These results show that DataSpace remains unsaturated and identify key challenges for improving data-agent reliability.

深度讲解Deep dive

DataSpace 以 410 个中英跨语言任务测试数据智能体能否从数据库、结构化文件、长文档和视频中发现并整合证据，最终生成可由确定性规则完整验证的表格。

它解决什么问题Problem

既有数据智能体基准通常分别测试 SQL、检索或开放分析，较少同时覆盖异构工作区的证据发现、跨载体关联、完整表格输出与无模型裁判的确定性评测。

核心方法Core method

DataSpace-Builder 从 EHRSQL 与 BULL 的问题、数据库和可执行 SQL 出发，联合转换问题、模式、实体和值的语言，再做保留谓词、边界与连接关系的任务级采样。采样表渲染为 CSV、JSON、SQLite、Markdown、PDF 和视频，SQL 结果形成候选金标。每项任务由两名专家盲解并配置类型、精度与顺序语义。评测器忽略列名和列顺序，按类型与精度规范化单元格，再按有序序列或无序多重集比较完整表格。

怎么工作How it works

  1. 取得自然语言问题、关系数据库和可执行 SQL。
  2. 联合转换问题、schema 与值，并通过结构检查和 SQL 重执行验证。
  3. 按主外键、谓词、边界值和目标实体进行约束感知采样。
  4. 把采样数据渲染为六类载体并做字段/证据原子校验。
  5. 两名专家盲解、核验金标和配置评测语义，分歧时修复复审。
  6. 智能体提交 CSV，评测器完成列对齐、类型规范化和完整行比较。

论文报告了什么Reported findings

  • 基准含 410 个任务、7439 个文件和 15.01GB 数据；265 项跨语言，134 项需组合多种模态。
  • 固定 DataSpace-Agent 后，最强骨干完成 272/410，准确率 66.34%；六个骨干的 oracle 并集为 81.46%。
  • 固定 MiMo-V2.5 后，五种 harness 准确率为 30.98%–46.34%，相差 15.36 个百分点。
  • 六个骨干在多模态任务上比单模态低 1.8–14.0 点，需要 join 的任务低 9.7–19.8 点。
  • 最强骨干 136 个失败中 71 个属于结果物化；输出目标理解与错误列投影合计 77/136。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：可作为 Harness 的异构工具与最终产物压力测试，尤其适合检查 late tool 结果接入后的实体、类型和 schema 一致性。
  • 编辑判断：基准在开始时给完整工作区并一次性提交 CSV，不覆盖流式输入、endpoint-before-generation 或运行中才出现的工具，需改造成事件回放。
  • 编辑判断：其价值位于数据与确定性验证层，与外挂 TTS 正交，也不评测原生全双工。

边界与局限Limits

  • 任务只从 EHRSQL 和 BULL 转换，领域集中于金融、宏观经济与医疗。
  • 文档和视频多由关系数据程序化或模型辅助渲染，缺少真实企业历史噪声与权限结构。
  • 全部输入公开，但只有 60 项开放金标与冻结配置，另 350 项只能走官方评测。
  • 完整表格二元匹配没有部分分，也不覆盖交互澄清或开放式报告。

代码与模型开放情况Code and model availability

部分开放Partial   官方仓库和 Hugging Face 数据以 MIT 发布评测器、DataSpace-Agent、五类 harness 适配器和全部 410 项输入；仅 60 项金标开放，350 项保留评测。没有专属模型权重，基线调用第三方模型端点。
