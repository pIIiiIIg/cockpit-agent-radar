Leveraging Beam Search Information for Confidence Estimation in E2E ASR

论文Paper · arxiv · 2026-07-31 · ◈ 4
摘要Summary
SR-CEM 从 beam search 的 token 分数、排名和上下文累计分数中学习轻量置信度，在多种 ASR 架构及噪声、会话条件下显著降低最坏校准误差。它可在 StreamingModelHarness 的 endpoint 后为转写和晚注入工具提供风险门控，但该系统仍是流式输入、判停后生成和外挂 TTS，并非原生全双工。 To estimate confidence for end-to-end Automatic Speech Recognition (ASR) systems, recent research has proposed Confidence Estimation Modules that incorporate features from the backbone ASR model. Most existing approaches, however, are architecture-dependent. In this paper, we propose the Score-Rank Confidence Estimation Module (SR-CEM), a lightweight module that leverages beam search information to generate token- and word-level confidence scores. Specifically, SR-CEM constructs features by combining the scores and ranks of tokens within a hypothesis. Experiments show that SR-CEM achieves effective calibration on both in-domain and out-of-domain English data. On the in-domain testset, it attains a Maximum Calibration Error of 4.50% and an Expected Calibration Error of 0.30% at the token level, significantly outperforming softmax confidence (20.04% and 1.75%, respectively). At the word level, SR-CEM achieves 8.17% and 0.35%, compared to 17.91% and 1.67% from softmax confidence. Furthermore, we demonstrate its robustness across hybrid and transducer ASR architectures with different decoding strategies, as well as on Dutch, noisy and conversational speech conditions. Our main finding is that SR-CEM is particularly effective in reducing Maximum Calibration Error, which is critical for reliable downstream use of ASR outputs, while maintaining architecture independence and generality across diverse evaluation conditions.

深度讲解Deep dive

SR-CEM 仅利用胜出假设在波束搜索中的分数、排名和上下文累积分数，以不到千参数的 MLP 输出 token/word 置信度；它显著改善最坏分桶校准误差，但依赖完整 beam-search 假设，并非在线端点检测器。

它解决什么问题Problem

E2E ASR 的 softmax 概率常因过度自信以及局部 token 概率与全局波束排名不一致而失准。既有置信度模块又多依赖隐藏状态、注意力或编码器输出，难以跨 Attention、CTC 和 RNN-T 架构迁移。

核心方法Core method

SR-CEM 为带 64 维隐藏层、ReLU 和 sigmoid 输出的轻量 MLP。token 级输入包含当前 token 分数与排名、前后文累计分数以及 top-4 候选分数，共 8 维；word 级输入包含 token 分数和、最大 token 排名、前后文累计分数及子词数，共 5 维。系统以最终假设和参考转写做 Levenshtein 对齐，将正确、插入和替换转成二分类标签，删除因没有对应预测单元而排除，再以二元交叉熵分别训练 token 与 word 模块。

怎么工作How it works

  1. ASR 通过 beam search 产生最终胜出假设，并保留各解码步的分数向量与 token 排名。
  2. 在完整假设上计算当前分数、前后文累计分数、top-k 分数及 word 聚合特征。
  3. 用参考转写做 Levenshtein 对齐，为可观测 token 和 word 标注正确或错误。
  4. 分别训练 token 级和 word 级 SR-CEM，推理时把校准置信度附加到最终转写。

论文报告了什么Reported findings

  • 正文 Table 2/3 中，LibriSpeech test-clean 的 token 级 MCE/ECE 为 4.50%/0.30%，softmax 为 20.04%/1.75%；word 级为 8.17%/0.35%，softmax 为 17.91%/1.67%。
  • 用 LibriSpeech 数据训练后直接测试 Common Voice，token/word MCE 为 19.59%/32.78%；改用目标域 Common Voice 数据训练后降至 6.67%/12.15%，说明优势仍明显依赖域匹配。
  • CTC-only 实验中 token/word MCE 为 3.27%/7.36%；RNN-T 中为 4.20%/11.95%，支持其跨已测试解码架构的适用性。
  • 正文效率分析报告 token/word 模块分别约 0.6k/0.4k 参数、模型占用低于 5KB，单句附加推理时间低于 0.1ms。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：StreamingModelHarness 是流式输入、端点判停门控后才生成、晚注入工具并使用外挂 TTS 的系统，不是原生全双工模型；SR-CEM 最适合在 endpoint 后给最终 ASR 转写加置信度，而不会改变这一架构定性。
  • 编辑判断：可用低置信度 word 阻止高风险工具参数直接进入晚注入流程，触发澄清、重识别或保守执行；但论文没有验证车内命令、工具调用正确率或安全收益。
  • 编辑判断：特征包含后续 token 累计分数，因此必须等完整假设形成，不能直接承担流式 endpoint、逐帧抢话或用户仍在说话时的早期决策。
  • 编辑判断：接入前必须确认 ASR 解码器能暴露 winning-hypothesis 的逐步分数、排名和 top-k；只返回最终文本或使用 greedy/aggressive pruning 的接口无法直接复用。

边界与局限Limits

  • 方法要求 beam search；论文明确指出 greedy decoding、激进剪枝或受约束解码会削弱特征信息。
  • 它只分析单一最佳假设，忽略分数接近的 N-best 候选，并且不能给删除错误分配置信度。
  • learned calibration curve 不是跨域或跨语言免训练的；Common Voice 域错配时 MCE 明显恶化，跨语言部署也要求重训。
  • word 级缺少 top-k 特征，校准弱于 token 级；全部实验基于定制 ESPnet 解码特征，未验证 StreamingModelHarness 的实际 ASR 后端和车内数据。
