Speech Emotion Recognition using Attention-based LSTM-Network with Residual Connection

论文Paper · arxiv · 2026-06-02 · ◈ 7
摘要Summary
ResLSTM-SA 是轻量语音情感识别模型，在 RAVDESS 说话人无关划分上以约46.8k参数达到最高 UAR 0.6517。适合作为座舱旁路情感感知模块，而非改写 Harness 主对话链路。 Speech emotion recognition is an important component of modern human-computer interaction systems. However, many state-of-the-art approaches rely on large pretrained models with high computational and memory requirements, limiting their applicability. This paper proposes ResLSTM-SA, a lightweight architecture that integrates residual connections with soft attention within an LSTM-based framework. Evaluated on the RAVDESS dataset under strict speaker-independent partitioning, the proposed model outperforms conventional attention-based LSTM baselines and several previously reported CNN- and hybrid CNN-LSTM architectures in terms of unweighted average recall (UAR). The best-performing variant (ResLSTM-SA-h64) achieves a maximum UAR of 0.6517 with only 46.8k trainable parameters, delivering competitive accuracy with three orders of magnitude fewer parameters than large-scale self-supervised alternatives, thereby enabling efficient deployment on edge devices and real-time voice assistants. The source code is available at https://github.com/Mak-Sim/ResLSTM-SER.

深度讲解Deep dive

ResLSTM-SA 把残差与 soft attention 引入轻量 LSTM 语音情感识别，在 RAVDESS 说话人无关设置上以46.8k参数达到最高 UAR 0.6517。

它解决什么问题Problem

许多先进 SER 依赖大规模自监督预训练模型，参数与算力高，难以部署到边缘或实时语音交互设备。

核心方法Core method

提出 ResLSTM-SA：在 LSTM-SA 基础上为初始 LSTM 层引入残差连接，并结合 soft attention；输入为 MFCC 与 chroma，在 RAVDESS 上严格说话人无关划分，比较不同隐藏维与基线。

怎么工作How it works

  1. 从语音提取 MFCC 与 chromagram 特征。
  2. 经带残差的 LSTM 与 soft attention 聚合序列表示。
  3. 在说话人无关划分上训练并报告 UAR。
  4. 与 LSTM-SA、CNN/混合模型及大参数自监督方案对照。

论文报告了什么Reported findings

  • 最佳配置 ResLSTM-SA-h64 平均 UAR 0.6232±0.0119，最高 UAR 0.6517，参数量46.8k。
  • 相对无残差 LSTM-SA，残差可带来最高约7.7个百分点的提升。
  • 同设定下，ResLSTM-SA-h32 等配置能在更少或相近参数下超过更大 LSTM-SA-h128。
  • 作者强调相对 wav2vec 等千万至上亿参数方案，该模型低三个数量级参数仍具竞争力。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 适合作为 Harness 外挂的轻量情感旁路，为播报策略或打断优先级提供标签，不必改主生成模型。
  • RAVDESS 表演语音与车内噪声条件差距大，上车前需重标定。
  • 情感标签不应直接等价于用户意图或安全相关决策。

边界与局限Limits

  • 只在 RAVDESS 报告主结果，泛化到其他语料未充分证明。
  • 特征工程式前端，未利用大规模自监督音频表示。
  • 实时端到端时延与车载麦克风阵列效果未测。
