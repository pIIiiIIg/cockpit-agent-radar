DrawAI: Agentic Benchmark and Workflow for Making Raster Images Editable

论文Paper · arxiv · 2026-08-01 · ◈ 8
摘要Summary
DrawAI 用解析计划和代码—渲染—验证—修订循环把位图重建为可编辑 SVG/PPTX，完整流程 Overall 达到 90.95。其 typed plan 与确定性验证可启发车控工具闭环，但离线多轮工作流不适合语音关键路径。 Recent image-generation models and multimodal agents can produce high-quality visuals for increasingly complex visual communication tasks. Yet their raster outputs remain difficult to use directly because meaningful content and relationships are flattened into pixels, preventing users from inspecting, modifying, rearranging, or reusing individual components. We formulate image-to-editable reconstruction, which recovers a structured, directly manipulable artifact from a raster image while preserving its visual and semantic content. The central challenge is to jointly satisfy Fidelity and Editability, which often trade off in practice. To study this task, we introduce DrawAI, comprising an agentic benchmark, DrawAI-Bench, and a reconstruction workflow, DrawAI-Flow. DrawAI-Bench spans scientific figures, presentation slides, posters, and diagrams, combining real and AI-generated images to reflect practical visual-creation scenarios. It evaluates Fidelity and Editability through a hybrid protocol of 39 criteria: deterministic rule-based metrics measure properties with direct correspondences, while asset-specific vision-language rubrics capture semantic and perceptual qualities for which exact matching is misleading. Besides, we propose DrawAI-Flow, a two-stage agentic workflow in which a Parser Agent turns extracted elements evidence into an explicit reconstruction plan, and a Reconstruction Agent realizes the plan as executable graphics code through an iterative code-render-validate-revise loop. On DrawAI-Bench, we systematically evaluate thirteen models across five agent harnesses to study the effects of model capability, harness choice, and workflow design. The results show that reconstruction quality and costs vary substantially across model-harness configurations, while DrawAI-Flow consistently improves editable structure.

深度讲解Deep dive

DrawAI 用显式解析计划和代码—渲染—验证—修订循环，把位图重建为可编辑 SVG/PPTX，并用 39 项指标同时衡量保真与可编辑性。

它解决什么问题Problem

位图把文字、对象和关系压平到像素，整图嵌入不可编辑，过度拆分又破坏布局与语义；现有方法也缺少同时评估视觉保真和结构可编辑性的统一基准。

核心方法Core method

DrawAI-Bench 收集四个领域共 80 张图，以 9 项确定性指标和 30 项 VLM rubric 评估。DrawAI-Flow 先合并 SAM3 区域和 OCR 文本，由 Parser Agent 生成元素级重建计划，再由 Reconstruction Agent 写成带语义 registry 的 SVG 程序，最多执行五轮 render–validate–revise，最后导出 PPTX。

怎么工作How it works

  1. SAM3 与 OCR 生成候选元素和文字。
  2. Parser Agent 对照整图去重、补漏、纠错并选择元素表示。
  3. 按计划生成原生文本、矢量、公式或局部位图素材。
  4. Reconstruction Agent 生成 SVG，并通过渲染比较做局部修复。
  5. 验证 SVG 后转换为可编辑 PPTX。

论文报告了什么Reported findings

  • 配对样本的 Fidelity 由 75.7 升至 78.7，Editability 由 56.4 升至 74.0；完整流程 Overall 达到 90.95。
  • 同一 80 图面板上 DrawAI Overall 为 91.0，Crafter 为 73.7，AutoFigure-Edit 为 73.4，Edit-Banana 为 41.0。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 可借鉴“感知结果→typed plan→执行→验证→局部修复”，让车控回执成为结构化状态而不是自由文本。
  • 该流程是离线分钟级到小时级任务，不涉及流式输入、语音判停或 TTS；若落到车控必须压缩为低延迟确定性状态机。

边界与局限Limits

  • 基准只有 80 张人工筛选图，30/39 项指标依赖 VLM rubric，且多数配置仍存在单图退化。
  • 可编辑性提升伴随公式、形状和连接线保真下降；精确位置、原生表格和实际 API 成本仍未解决。

代码与模型开放情况Code and model availability
