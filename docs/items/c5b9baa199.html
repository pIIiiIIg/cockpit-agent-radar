SemBridge: Semantic Token Anchoring for Continuous-Latent Autoregressive Speech Generation

论文Paper · arxiv · 2026-08-07 · ◈ 4
摘要Summary
SemBridge 用离散语义 token 在训练期监督连续潜变量自回归语音模型，让隐藏状态和声学潜空间共享同一语义锚点，而推理时仍只生成连续潜变量。论文在零样本 TTS 和歌声合成上报告内容准确性提升，同时保持有竞争力的说话人相似度与感知质量。 Continuous-latent autoregressive speech generation has emerged as a promising alternative to discrete-token modeling by avoiding quantization loss and preserving richer acoustic information. However, continuous acoustic targets do not ex- pose linguistic structure as explicit token-level prediction tar- gets. Consequently, the autoregressive language model (LM) must acquire linguistic structure indirectly through acous- tic prediction, which can compromise the content fidelity of generated speech. We propose SemBridge, a training-only semantic-token anchoring framework for continuous-latent autoregressive speech generation. SemBridge uses discrete se- mantic tokens to directly supervise autoregressive LM states and employs a Semantic-Aligned Acoustic VAE to organize the continuous target space under the same semantic refer- ence. The semantic supervision is used only during train- ing, while inference remains entirely continuous. We evalu- ate SemBridge on zero-shot text-to-speech (TTS) and score- conditioned singing voice synthesis (SVS). Across multi- ple benchmarks, SemBridge improves content accuracy, as measured by word and character error rates (WER/CER), while maintaining competitive speaker similarity and percep- tual quality. Experimental results demonstrate that explicit semantic-token supervision for autoregressive state learning is an effective and general direction for continuous speech generation. Speech samples are available.1 The model code and checkpoints will be available at https://github.com/ASLP- lab/SemBridge

深度讲解Deep dive

训练时借离散语义 token 教会连续语音生成器“说什么”，推理时移除语义头，保留连续潜变量对声学细节的表达能力。

它解决什么问题Problem

离散语音 token 有明确的语言结构，却受量化损失限制；连续声学潜变量保留更多细节，但没有逐步显式语义目标，自回归 LM 只能从声学生成目标中间接学语言结构，容易损害内容忠实度。已有连续特征对齐方法也没有把离散语义类别直接监督到自回归隐藏状态。

核心方法Core method

SemBridge 使用冻结的 GLM-4 语义 tokenizer 同时产生 token 级嵌入和离散 ID。第一阶段训练 Semantic-Aligned Acoustic VAE（SA-VAE），把连续声学 patch 对齐到语义嵌入；第二阶段冻结 SA-VAE 与 tokenizer，在原有 flow-matching、停止预测等生成目标之外，用对应离散 ID 监督指定 Transformer 层的隐藏状态。语义对齐投影和分类头只在训练期存在，推理仍由连续 patch、因果 LM 和局部扩散 Transformer 完成。

怎么工作How it works

  1. 从训练波形提取离散语义 ID 及其 token 嵌入，同时由 SA-VAE 编码连续声学帧。
  2. 把连续帧合并为与语义 token 时间率一致的声学 patch，并训练 SA-VAE 做声学重建和语义嵌入对齐。
  3. 冻结 SA-VAE 与语义 tokenizer，用离散语义 ID 对自回归 LM 的选定中间层施加分类监督。
  4. 推理时删除对齐投影和语义头，仅根据文本或乐谱条件、可选音频提示及历史连续 patch 自回归生成，再解码为波形。

论文报告了什么Reported findings

  • SA-VAE 在 2.5 万小时音频上训练，其中包括 2 万小时公开语音和 5000 小时内部歌声数据。
  • 匹配的 TTS 实验使用 10 万小时双语开源 VoxBox；联合 TTS/SVS 模型加入 2 万小时内部歌声后使用 12 万小时多任务语料。
  • 连续生成骨干含 800.15M 可训练参数，SA-VAE 含 86.48M 参数；对齐投影和语义锚定模块分别增加 2.43M 与 16.79M 参数，且二者在推理时移除。
  • SA-VAE 将 44.1 kHz 波形编码为 25 Hz、64 维连续潜帧；冻结语义 tokenizer 的速率为 12.5 Hz，词表大小为 16,384。
  • 论文报告 SemBridge 在零样本 TTS 与乐谱条件 SVS 的多个基准上持续降低 WER/CER，同时保持有竞争力的说话人相似度和感知质量。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 这是九篇中与外部 TTS 最直接相关的一篇，可启发 StreamingModelHarness 的语音输出后端在内容忠实度与声学细节之间取得更好平衡。
  • 它需要训练或替换 TTS 模型，不是对现有 Harness 编排层的即插即用修改；对话话尾检测、晚期工具注入和响应调度不在论文范围内。
  • 连续潜变量自回归语音生成不等于输入输出同时进行的原生模型层全双工，不能据此改写 Harness 的能力定位。

边界与局限Limits

  • 关键训练规模很大，并使用内部歌声数据和多卡 H20 训练，完整复现实验有较高数据与算力门槛。
  • 语义 tokenizer、锚定层位置和损失权重会引入内容准确性与合成质量的权衡，论文的层级分析也观察到这一点。
  • 主要任务是离线零样本 TTS/SVS，未评估实时首包延迟、流式稳定性、打断恢复或座舱噪声条件。
  • 论文只声明代码和 checkpoint 将公开，当前材料不足以确认发布物是否已经完整可用。
