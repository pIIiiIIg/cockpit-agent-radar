Deferred Audio Pruning with Local Audio-Visual Dynamics for Omni-LLMs

论文Paper · arxiv · 2026-08-09 · ◈ 11
摘要Summary
A-PACK（Deferred Audio Pruning）先保留高密度音频、按局部音视频动态压缩视频，再在 LLM 内按查询相关度剪枝 token/KV；报告最高约 78% prefill FLOPs 下降与最高约 2.21× 解码吞吐。可借鉴到座舱多模态上下文压缩，但属于推理期 token 治理，不是原生全双工或判停中间件。 Omni-modal LLMs jointly process audio, video, and text, but long multimodal sequences incur substantial prefill and KV-cache costs. Existing omni-modal compression methods primarily focus on pre-LLM token reduction, leaving modality-specific compression across the LLM boundary underexplored. We propose A-PACK, a two-stage framework that defers audio pruning until query-conditioned multimodal interactions emerge. Our analysis shows that audio exhibits higher task-relevant information density and representational diversity per token than video. We further find that local audio-visual dynamics provide a more effective cue for visual selection than token-wise matching. We therefore preserve audio and compress video with local dynamics before the LLM, then progressively prune low-relevance audio and visual tokens and their KV-cache entries inside the LLM. Across four benchmarks on Qwen2.5-Omni-7B/3B, A-PACK achieves the strongest average performance among the evaluated prior methods while reducing prefill FLOPs by up to 78% and improving decoding throughput by up to 2.21x.

深度讲解Deep dive

A-PACK 在 Omni-LLM 中先保音频、用局部音视频动态压缩视频，再在 LLM 内按查询相关度渐进剪枝音视频 token 与 KV，以降低预填充与缓存成本。

它解决什么问题Problem

长音视频序列使 Omni-LLM 的 prefill 与 KV cache 代价很高；既有压缩多在进 LLM 前做，跨 LLM 边界的模态差异化压缩不足，过早剪音频易丢掉高信息密度证据。

核心方法Core method

两阶段训练无关框架：LLM 前保留音频并用局部音视频动态引导视频压缩；进入 LLM 后，待查询条件化的多模态交互出现，再渐进剪掉低相关音频/视觉 token 及其 KV。

怎么工作How it works

  1. 分析显示单位 token 上音频任务相关信息密度通常高于视频。
  2. Pre-LLM：保留音频，按局部音视频动态选择视觉 token。
  3. Inner-LLM：从中层起按查询相关度逐层剪枝多模态 token 与对应 KV。
  4. 在 Qwen2.5-Omni-7B/3B 与多个 omni 基准上对比训练无关压缩基线。

论文报告了什么Reported findings

  • 在四个基准、Qwen2.5-Omni-7B/3B 上，A-PACK 在所评训练无关方法中平均表现最强，并报告最高可降约 78% prefill FLOPs、解码吞吐最高约 2.21×。
  • 7B 模型在 35% prefill-FLOPs 档位上保留 Full-Tokens 准确率的 98.8%。
  • 结论还报告 AVUT 场景 GPU 显存可降低约 2.3 GB。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 对座舱长视频+语音多模态上下文的 KV/预填充治理有直接启发：可优先保音频证据、延后剪音频。
  • 方法是训练无关的模型内 token/KV 剪枝，不是 Harness 判停策略；要接入需挂在推理运行时而非只改提示词。
  • 不应默认等于全双工语音中间件；其收益以 Omni 理解吞吐为主。
