Modular Deep Learning Framework for Assistive Perception: Gaze, Affect, and Speaker Identification

论文Paper · arxiv · 2025-11-25 · ◈ 4
摘要Summary
该工作分别训练眼睛状态、表情和五人封闭集说话人分类器，报告 93.0%、97.8% 和 96.89% 准确率，但三模块尚未集成或测量实时延迟。它最多是座舱旁路感知候选，不能把五人分类结果当作车控身份认证。 Developing comprehensive assistive technologies requires the seamless integration of visual and auditory perception. This research evaluates the feasibility of a modular architecture inspired by core functionalities of perceptive systems like 'Smart Eye.' We propose and benchmark three independent sensing modules: a Convolutional Neural Network (CNN) for eye state detection (drowsiness/attention), a deep CNN for facial expression recognition, and a Long Short-Term Memory (LSTM) network for voice-based speaker identification. Utilizing the Eyes Image, FER2013, and customized audio datasets, our models achieved accuracies of 93.0%, 97.8%, and 96.89%, respectively. This study demonstrates that lightweight, domain-specific models can achieve high fidelity on discrete tasks, establishing a validated foundation for future real-time, multimodal integration in resource-constrained assistive devices.

深度讲解Deep dive

该工作分别训练眼睛状态、七类表情和五人封闭集说话人分类器，但尚未把三个模块集成为实时多模态系统。

它解决什么问题Problem

辅助感知设备希望同时判断注意/疲劳、表情和说话人身份，但在资源受限设备上是否能以多个轻量专用模型完成这些离散任务仍需验证。

核心方法Core method

论文分别训练眼睛开闭 CNN、FER2013 表情 CNN 和基于 MFCC 的 128 单元 LSTM 说话人分类器。音频实验包含五人、每人约 1,500 个一秒片段，并按 70/15/15 划分；设想的系统会先做说话人认证，再监测眼睛状态和表情，但正文没有实现联合管线。

怎么工作How it works

  1. 分别预处理眼睛图像、表情图像和一秒音频片段。
  2. 独立训练三个分类器。
  3. 在各自测试或验证集计算准确率、F1 和混淆矩阵。
  4. 未来再串成实时级联；该步骤尚未完成。

论文报告了什么Reported findings

  • 眼睛开闭准确率为 93.0%，两类 F1 均为 0.93；FER2013 七类表情准确率报告为 97.8%。
  • 五人封闭集说话人识别准确率为 96.89%，weighted F1 为 0.96。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 眼睛和表情可作为带时间戳的旁路事件，在下一轮进入安全策略或上下文，而不是直接污染主音频 KV。
  • 五人封闭集分类不能当作车控身份认证；论文没有连续收音、时延、遮挡、车内噪声、endpoint 或 TTS 证据。

边界与局限Limits

  • 三模块从未联合运行，也未报告参数量、FLOPs、内存或推理时延，因此“轻量”和“实时”没有实测支持。
  • FER2013 的异常高结果缺少跨数据集与重复实验；说话人随机切片可能共享同一原始录音条件，且不能拒绝未知说话者。
