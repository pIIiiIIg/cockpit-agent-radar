V-Mem: Modality-Routed Retrieval for Long-Term Multimodal Agentic Memory

论文Paper · arxiv · 2026-08-02 · ◈ 12
摘要Summary
V-Mem 把多模态对话按 round 保存，并按查询与目标模态路由检索，用同轮绑定和生成式搜索锚跨越图文差距；Mem-Gallery Overall 达到 0.825。其增量外部记忆可缓解 Harness 多轮 KV 累积，但已验证路径仍需完整轮次和文本转写，不能消除判停或 TTS 延迟。 Interaction between users and LLM agents is increasingly multimodal: conversations interleave text with images, and a later question may target either. Yet most agent memories are designed around text, and even the few that support multimodal conversations still fail on vision-related questions. We trace this failure to an assumption behind the similarity search they rely on: in the index space, a query lies close to the relevant evidence that answers it. In multimodal settings, two gaps break it. By the modality gap, a query lies closer to memory content of its own modality than to evidence in another, even in a trained joint embedding space. By the similarity-relevance gap, the content most similar to a query is often not the evidence that answers it, most acutely when a query carries both text and image and its evidence resembles neither part alone. We present V-Mem, a multimodal agentic memory system that routes retrieval by the modality of the query and that of the target evidence, both recognized from the query alone. To cross the modality gap, V-Mem organizes the conversation into rounds and returns the target-modality content from the same round as the match, without comparing across modalities. To close the similarity-relevance gap, it searches with an LLM-generated anchor that sits closer to the relevant evidence than the query does: a hypothetical caption for a text-only query seeking an image, and an enriched search anchor, the query text plus relevant keywords extracted from the query image, when the evidence is reachable only by combining the two. On Mem-Gallery, V-Mem reaches an LLM-judge score of 0.82 versus 0.56 for the second best, with the largest margin on questions carrying an image (0.87, no baseline above 0.47); on LoCoMo it scores 0.69 versus 0.58.

深度讲解Deep dive

V-Mem 按查询与目标证据的模态路由记忆检索，并通过同轮绑定和生成式搜索锚跨越图文模态差距。

它解决什么问题Problem

多模态对话记忆中，查询往往更接近同模态内容而非真正证据；同时最相似的内容也未必回答问题，普通统一向量检索因此在图像相关问题上失效。

核心方法Core method

V-Mem 把每次用户—助手交换保存为 round，文本与原图进入独立 lane 并保留 round 绑定。规则识别 text→text、text→image、image+text→image、image+text→text 四种路由；跨模态时先在查询模态检索，再返回同一 round 的目标模态。text→image 使用假想 caption，image+text→text 则把视觉关键词加入搜索锚，最后以 RRF 合并排名。

怎么工作How it works

  1. 新 round 到来时本地编码文本和图像并追加，不重写既有记忆。
  2. 根据查询是否带图和目标关键词判断查询/目标模态。
  3. 激活所需 lane，必要时生成假想 caption 或视觉关键词增强锚。
  4. 对 unit 排名后折叠为 round，注入 top round 和邻轮供主干回答。

论文报告了什么Reported findings

  • 使用 gpt-4o-mini 时，Mem-Gallery Overall 为 0.825，最强基线 Omni 为 0.561；本地 Qwen2.5-VL-32B 下为 0.829 对 0.628。
  • LoCoMo Overall 为 0.690，Omni 为 0.583；但开放域类别只有 0.375，低于 M2A 的 0.477。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 增量、无需 LLM 重建的外部记忆可缓解 Harness 多轮 KV 累积，并按模态选择需要注入的历史证据。
  • 其写入单元是已完成 round，音频也只按转写文本处理；生成搜索锚增加约束前查询时延，不能消除判停或外挂 TTS 瓶颈。

边界与局限Limits

  • 只验证文本和图像，未建立音频 lane，也未测试视频或 100ms 级连续流。
  • 效果依赖回答主干利用检索上下文的能力；Qwen2.5-VL-7B 下 V-Mem 反而低于 Omni，且生成锚显著增加每题 token 与时延。
