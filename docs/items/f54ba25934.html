CLIP-CC-Bench: Evaluating Paragraph-Level Video Descriptions in Video-Language Models

论文Paper · hf · 2026-08-04 · ◈ 5
摘要Summary
CLIP-CC-Bench 面向长视频段落描述，使用 200 个 90 秒电影片段、专家段落参考和五个嵌入模型组成的多评审协议，同时衡量整体叙事与句级细节。它补足了短片字幕和问答基准难以评价长程故事理解的问题，但本质上仍是离线视频描述评测，并非实时语音交互方案。 Benchmarking video-language models has largely focused on short clips and single-sentence metrics, leaving open whether current systems can generate accurate long-form, paragraph-level descriptions. We introduce CLIP-CC-Bench, an evaluation suite for long-form video description built from 5 hours of movie content segmented into 90-second clips, each paired with an expert-written paragraph-style reference. The evaluation suite employs an ensemble of five state-of-the-art LLM-based embedding models to increase reliability and mitigate single-model bias, and applies two complementary methodologies: (i) coarse-grained semantic matching and (ii) fine-grained semantic matching to compare model-generated descriptions against CLIP-CC-Bench references. Using this framework, we evaluate 17 state-of-the-art video-language models and report both their Borda-aggregated rankings and their average scores on CLIP-CC-Bench. We further quantify the protocol's internal reliability through inter-judge agreement and bootstrap ranking stability. We release standardized evaluation scripts, model outputs, and aggregation tools at https://github.com/Multimodal-Intelligence-Lab/CLIP-CC-Bench to support reproducibility. CLIP-CC-Bench provides a practical evaluation framework for long-form video description, filling a gap left by existing short-clip and QA-only benchmarks.

深度讲解Deep dive

把长视频描述拆成“整段是否讲对”和“细节是否覆盖”两层语义匹配，再用五个嵌入评审的 Borda 排名降低单一评审的尺度偏差。

它解决什么问题Problem

现有视频语言基准多面向短片、单句字幕或离散问答；BLEU、ROUGE、METEOR 等词面指标难以衡量段落级语义、时序连贯性和完整故事理解。单一 LLM 评审又可能不稳定，因此长视频的开放式段落描述缺少可复现、可比较的评测协议。

核心方法Core method

数据集从电影内容中选取长片段，由专家编写不含专名和特定文化指代的段落参考。评测时，五个来自 MTEB 排行的嵌入模型分别担任评审：粗粒度分数比较整段向量的余弦相似度，细粒度分数对预测句与参考句做双向最佳匹配并计算精确率、召回率和 F1；每位评审再对粗、细分数取调和均值，最终以 Borda count 汇总模型名次。

怎么工作How it works

  1. 将约 5 小时电影内容切分并筛选为 200 个 90 秒片段，由专家撰写段落式参考描述。
  2. 让待测 VLM 使用统一提示词、temperature=0、max_tokens=5000 和贪心解码生成长描述。
  3. 由五个嵌入评审分别计算整段语义相似度和句级双向匹配 F1，并合成为每位评审的分数。
  4. 按各评审的模型名次进行 Borda 聚合，同时用评审间一致性与 bootstrap 排名稳定性检查协议内部可靠性。

论文报告了什么Reported findings

  • 基准包含约 5 小时电影内容、200 个 90 秒片段及对应的专家段落参考。
  • 论文评测了 17 个视频语言模型；由于所有模型都缺少第 126 号片段的输出，最终指标在相同的 199 个片段上配对计算。
  • 评测采用五个 LLM 嵌入模型作为独立评审，并同时报告粗粒度、细粒度与 Borda 聚合结果。
  • 论文通过评审间一致性和 bootstrap 排名稳定性量化了协议的内部可靠性。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 对 StreamingModelHarness 的直接相关性较低：论文评的是离线长视频段落生成，不涉及流式音频、话尾检测、工具调用或 TTS。
  • 可借鉴其“粗粒度整体质量 + 细粒度事实覆盖 + 多评审排序”的方法，为座舱对话摘要、长回答或场景说明设计更稳健的离线回归评测。
  • 它不能证明 Harness 具备模型层原生全双工能力；Harness 仍是音频输入、话尾检测、生成、晚期工具注入和外部 TTS 串联的系统。

边界与局限Limits

  • 素材集中于电影片段，未覆盖真实世界长视频、直播或交互式场景。
  • 五个评审仍同属文本嵌入模型，集成可缓解单模型偏差，却不能等同于独立的人类事实核验。
  • 语义相似度可能奖励意思接近但细节错误的描述；单一专家参考也未必覆盖所有同样正确的叙述方式。
  • 统一帧上限差异较大，模型最大可处理帧数不同，排名同时反映模型能力与采样配置。
