Understand Before Detect: Vision--Language Learning for Omni-Domain Infrared Small Target Detection

论文Paper · arxiv · 2026-08-07 · ◈ 8
摘要Summary
JinSight 提出先理解再检测的红外小目标视觉-语言框架，并构建逾39k标注的 OmniIRST-VL 基准，在 WideIRSTD 上相对既有方法报告超过14%的 IoU 提升。对 StreamingModelHarness 基本无关，属红外感知而非语音双工。 Omni-domain infrared small target (IRST) detection is crucial for infrared surveillance, yet remains challenging due to heterogeneous imaging domains and inconsistent target characteristics. Previous deep learning-based methods have been developed for visual-only paradigms and achieved promising performance on domain-specific tasks. However, existing methods follow the task-specific supervised learning paradigm. This paradigm simplifies the full-scene infrared observations to sparse target supervision, discarding the semantics that remain invariant across heterogeneous domains. Consequently, detection performance suffers substantially under domain shifts. To handle this issue, we introduce \textbf{``understand before detect''}, a paradigm that formulates omni-domain IRST detection as an understanding-driven process, where holistic infrared target understanding precedes precise detection. Building on this paradigm, we propose \textbf{JinSight}, which first develops holistic IRST understanding through language supervision and then transfers the learned cross-domain representations to precise small-target detection. By grounding infrared representations in language semantics, JinSight enables a single model to generalize across heterogeneous infrared domains. We then introduce Latent Semantic Interaction (LSI), which exchanges language-aligned global semantics with fine-grained spatial features in a compact low-rank space. To address the lack of multimodal omni-domain IRST benchmarks, we build \textbf{OmniIRST-VL}, the first large-scale, highly diverse vision--language dataset for omni-domain IRST detection. It comprises over 39k annotations across six complementary instruction tasks covering both scene-level understanding and target-centric reasoning.

深度讲解Deep dive

JinSight 用 IRST 定向视觉指令微调与潜语义交互做全域红外小目标检测，并发布 OmniIRST-VL；在 WideIRSTD 上相对 SOTA 报告逾14% IoU 提升。

它解决什么问题Problem

全域红外小目标检测面临成像域异构与目标特性不一致；既有视觉专用监督把全场景简化为稀疏监督，缺少“先理解场景再检测”的多模态基准与方法。

核心方法Core method

构建 OmniIRST-VL（基于 WideIRSTD，含逾39k图像-指令-回答）；提出 JinSight：IRST 定向视觉指令微调，并用 Latent Semantic Interaction 把全局语义与细粒度空间特征交互，再用于检测。

怎么工作How it works

  1. 收集/标注全域红外图像并生成场景向与目标向指令。
  2. 在 VLM 上做 IRST 定向指令微调。
  3. 通过 LSI 模块融合全局语义与局部空间特征。
  4. 在 OmniIRST-VL 与 WideIRSTD/跨数据集设定上评测理解与检测指标。

论文报告了什么Reported findings

  • OmniIRST-VL 含逾39k图像-指令-回答标注，覆盖多种红外成像设定。
  • 作者报告 JinSight 在 WideIRSTD 上相对既有方法 IoU 提升超过14%。
  • 相对其基线，完整方法相对提升 IoU 5.45%、Pd 4.94%；单独指令或 LSI 也有较小正增益。
  • 跨 NUDT-SIRST、NUAA-SIRST、IRSTD-1K 的留一迁移中，文称 JinSight 在 Pd 与 IoU 上均最高。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 主题是红外监视小目标检测，与座舱语音 StreamingModelHarness 无直接工程接口。
  • “先理解再检测”的指令监督思路，至多对未来视觉事件旁路有概念启发，不应写入语音判停主链。
  • 不提供双工、打断或外挂 TTS 相关结果。

边界与局限Limits

  • 数据与评测围绕红外小目标，不覆盖车内座舱交互。
  • 正文写数据集与权重将在发表后公开，当前开放状态仍待核验。
  • IoU 提升幅度依赖所选 SOTA 对照与 WideIRSTD 协议。
