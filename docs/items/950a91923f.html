IRAF: Interference-Resilient Adaptive Fusion for Noise-Robust End-to-End Full-Duplex Spoken Dialogue Systems

论文Paper · arxiv · 2026-06-04 · ◈ 28
摘要Summary
IRAF 提出一种抗干扰自适应融合机制，解决端到端全双工对话模型在真实声学环境下的退化问题：干扰说话人声音漏入用户麦克风会被编码进用户query，污染 LLM 条件导致输出不稳。对座舱场景直接对口——车内乘客交谈、媒体声正是最典型的干扰源，其双通道融合与抗干扰思路可借鉴到流式 KV 注入的前端处理中。 Full-duplex spoken dialogue models allow voice agents to listen and speak concurrently, enabling natural interaction with real-time overlap. 深度讲解Deep dive

IRAF 是插在全双工语音模型内部的逐帧音频可信度门，用目标声纹降低背景说话人对 LLM 上下文的污染。

它解决什么问题Problem

端到端双通道模型通常把用户音频和助手侧表示直接融合。在多人或有背景语音时，非目标说话人的声音也会进入条件上下文，造成误接话、漏响应和答案跑偏。

核心方法Core method

IRAF 将目标说话人 embedding 与当前及历史用户音频 embedding 输入一个轻量因果 Transformer，预测范围为 0 到 2 的逐帧可靠性门。门值先缩放用户音频表示，再与助手表示融合，因此既能抑制干扰帧，也能保留或增强目标用户帧。

怎么工作How it works

  1. ECAPA-TDNN 提取目标说话人声纹。
  2. 流式语音编码器以约 80ms 粒度产生用户音频表示。
  3. 单层因果 Transformer 预测每帧可靠性门。
  4. 缩放后的音频表示进入 LLM，模型继续生成文本和语音。

论文报告了什么Reported findings

  • 在 InstructS2S-200K 的干扰说话人条件下，响应成功率由噪声增强基线的 69.2% 提升到 91.0%。
  • 同一条件下响应延迟由 0.97 秒降至 0.82 秒，打断停止成功率达到 99.8%。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 可借鉴为“声纹 + 座位/波束 + AEC 置信度”的多人音频门，再决定哪些音频允许写入流式 KV。
  • 不应直接照搬单目标用户设计，否则可能误杀副驾和后排乘员的合法指令。

边界与局限Limits

  • 实验干扰主要由 MUSAN 模拟，未覆盖真实车内混响、扬声器回声和麦克风阵列。
  • IRAF 位于模型 embedding 融合层，需要联合训练；不是可直接挂到现有 Harness 的独立服务。
