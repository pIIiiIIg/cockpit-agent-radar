Light-Omni: Reflex over Reasoning in Agentic Video Understanding with Long-Term Memory

论文Paper · arxiv · 2026-07-06 · ◈ 14
摘要Summary
Light-Omni 以有限大小的分层全局记忆和一次前向产生的动作、检索 latent state，替代视频 agent 的多轮规划搜索。它最值得 StreamingModelHarness 借鉴的是 reaction head 与异步记忆整合；公开实现仍由 VAD/静默端点触发并使用非流式外挂 TTS，不是原生全双工。 Agentic video understanding equips models with long-term memory to autonomously process and respond to continuous, long-horizon multimodal streams. However, advanced video agents often rely on ``detective-style'' iterative reasoning for action control (e.g., $\mathtt{search}$) and evidence aggregation, incurring prohibitive costs and latency. We argue that such heavy reasoning primarily compensates for the lack of global context and semantic misalignment in retrieval. This paper introduces Light-Omni, a multimodal agent framework for reflexive and lightweight video understanding. It achieves this through dual contextual states that instantly build the required context in a single forward pass. First, we maintain a global state, a finite-sized multimodal script continuously consolidated from episodic memory, serving as the global context for Light-Omni. Through hierarchical merging, it preserves recent details while summarizing past events. Second, conditioned on this global context, we generate a parametric latent state that directly drives autonomous actions and produces retrieval embeddings, with minimal latency. Benefiting from this coupled design, Light-Omni achieves semantically aligned retrieval and reflexive responses while avoiding iterative reasoning. Extensive experiments validate the effectiveness of Light-Omni across multiple video benchmarks. Notably, it outperforms M3-Agent with an average 2.4% accuracy gain, a 12.1$\times$ speedup, and a 2.6$\times$ improvement in GPU memory efficiency. Furthermore, it serves as a memory system to enhance both the performance and efficiency of existing MLLMs. Project page: https://clare-nie.github.io/Light-Omni.

深度讲解Deep dive

Light-Omni 用有限大小的分层全局记忆和一次前向产生的动作、检索 latent state，取代视频 agent 的多轮规划搜索；前台响应明显加快，但记忆构建仍昂贵，公开实现也依赖 VAD/静默端点而非原生全双工。

它解决什么问题Problem

长视频超出模型上下文；普通 RAG 存在用户查询与碎片化视频记忆的语义错位，多轮查询重写、规划和工具搜索又增加延迟与显存。

核心方法Core method

长期记忆分为用户档案、语义事实和带时间戳的 episodic script。Global State 采用分层合并：每层达到 9 个节点时合并最老 8 个，以保留近期细节和远期摘要。系统在 Global State、当前输入和 soft prompts 上做一次前向，不同隐藏状态分别进入 speech/search 二分类头和检索 MLP；latent embedding 与文本检索 embedding 相加。Memory、Generation、Reaction 三套 LoRA 分工训练，交互后把记忆整合放入后台队列。

怎么工作How it works

  1. VAD、视觉和人脸处理把连续流切成最长约 30 秒的片段。
  2. Global State 与当前片段经一次前向产生动作和检索向量。
  3. 按需检索语义与 episodic 记忆并生成回答。
  4. 前台返回后把交互入队，后台异步更新档案和分层全局状态。

论文报告了什么Reported findings

  • 在 VideoMME-long 上，Qwen2.5-Omni-7B 的准确率从 55.3% 提至 66.1%，延迟从 48.8 秒降至 2.22 秒，显存从 81.7 GB 降至 24.0 GB。
  • 相对 M3-Agent，VideoMME-long 准确率为 66.1% 对 61.8%，交互总延迟为 2.28 对 25.91 秒；离线记忆构建仍需 1753.30 秒。
  • LVBench 音频噪声下 Light-Omni 下降 1.3 个百分点，Naive RAG 与 RAG-Rewrite 分别下降 5.1 和 3.7 个百分点。
  • OVO-Bench 平均准确率为 54.51%，Dispider 为 51.46%，Flash-VStream 为 29.10%。
  • 移除 episodic memory 后三基准平均准确率从 64.84% 降至 60.50%；移除 Global State 后延迟从 2.37 秒降至 0.81 秒、准确率降至 62.89%。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：可为 StreamingModelHarness 增加轻量 reaction head、长期记忆和异步 consolidation，减少 endpoint 后不必要的生成与多轮检索。
  • 编辑判断：公开 demo 同样由 VAD/静默端点触发，禁用 Qwen talker，并以非流式 CosyVoice 外挂 TTS；这与 Harness 一样不是模型层原生全双工。
  • 编辑判断：当前动作只有 search/speech，方法可把部分晚注入检索前移到快速动作决策，但没有证明生成途中动态工具注入可靠。

边界与局限Limits

  • “近 O(1)”只描述前台响应，离线记忆构建仍随视频增长且平均耗时很高。
  • 基线使用不同 backbone、调用模式和 API 延迟口径，端到端成本并未完全对齐。
  • 用户档案含人脸、身份、关系和偏好，但论文未评测隐私、误识别、删除请求或记忆投毒。
