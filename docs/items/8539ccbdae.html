DuplexSLA: A Full-Duplex Spoken Language Model with Synchronized Speech, Language, and Action

摘要Summary
DuplexSLA 提出语音、语言、动作三者同步的全双工口语模型，在双工主干内原生开辟了一条用于对话中规划和工具调用的通道，使 agentic 行为不再被绑在轮次边界或外部级联上。这正是本站“晚注入工具清单”痛点的正面回应：可借鉴其在流式生成中途插入工具调用而不打断听说的设计。 Recent advances in spoken dialogue language models have shifted from turn-based to full-duplex designs, where the model continuously listens to the user while generating responses. However, existing duplex backbones still lack a native channel for in-conversation planning and tool calling, leaving real-time agentic behaviour either tied to turn boundaries or relegated to an external cascade. 深度讲解Deep dive

DuplexSLA 在统一的 160ms 时间线上联合生成助手语音与独立 Action 流，使听、说、规划和工具调用可以并行。

它解决什么问题Problem

现有全双工语音模型通常没有原生工具通道：工具调用要么等待轮次结束，要么由外部级联处理，造成动作延迟并割裂口播。

核心方法Core method

它采用双音频流、三语义通道：连续用户音频、离散助手语音，以及限速的文本 Action 通道。Action 通道承载转写、规划、response/interrupt/backchannel 标签和结构化工具 JSON，每个动作都带明确的 160ms 时间位置。

怎么工作How it works

  1. 每个 160ms 块接收两份 80ms 用户音频特征。
  2. 同一主干预测一个文本锚点和四个 40ms 助手语音 token。
  3. Action 通道每块最多输出 10 个文本 token，超出部分顺延。
  4. 工具调用与助手口播并行，interrupt 标签可让语音迅速切换为静音。

论文报告了什么Reported findings

  • 工具调用平均延迟为 0.64 秒，ASR+LLM 级联为 2.77 秒；对应准确率分别为 85.56% 和 91.33%。
  • 论文报告正常接话、停顿、打断和附和识别准确率分别为 96.00%、93.33%、99.33% 和 98.33%。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 最值得借鉴的是独立、带时间戳的 Action 事件流，可逐步替代混在口播文本中的 §车控标签§。
  • 短期仍应保留本地确定性执行层；模型产生 Action 不等于动作可以无条件落车。

边界与局限Limits

  • 该能力依赖约 32 万小时持续预训练和约 5 万小时后训练，不是 Harness 级的小改。
  • 工具结果显示速度显著提升，但准确率略低于级联基线。
