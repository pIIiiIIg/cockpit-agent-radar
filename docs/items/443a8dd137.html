SymbOmni: Evolving Agentic Omni Models via Symbolic Concept Learning

论文Paper · arxiv · 2026-07-13 · ◈ 9
摘要Summary
SymbOmni 把 ComfyUI 成功与失败轨迹抽象成可检索、组合和修正的符号工作流指令，减少视觉任务反复从零规划。它可为 StreamingModelHarness 缓存 endpoint 后的工具计划，但不处理流式感知、生成中途工具注入或语音全双工。 Visual generation is increasingly ubiquitous in diverse domains, from text-to-image/video synthesis to multimodal interactive creation. Yet prevailing monolithic models remain fundamentally constrained by their inability to learn cumulatively and evolve autonomously, which is a limitation we term the "perpetual novice" problem. They lack mechanisms for structuring experience into reusable knowledge and therefore rely on brittle, "from-scratch" reasoning for each task, resulting in poor compositional generalization and inefficient knowledge retention. Motivated by these limitations, we propose SymbOmni, an agentic omni-model designed for cumulative evolution through Symbolic Concept Learning. At its core is the Symbolic Concept Box, an optimizable memory module that abstracts low-level operations into reusable Symbolic Workflow Instructions. SymbOmni operates through an induction-transduction cycle: experiences are abstracted into symbolic concepts (induction), which are then adaptively composed to solve novel tasks (transduction). The training is done by verbalized backpropagation with language-based feedback to enable continuous self-improvement without gradient-based model fine-tuning. Comprehensive experiments validate that (I) SymbOmni significantly outperforms existing agent-based systems for iterative creation and also surpasses closed-source models (e.g., Nano Banana, GPT-Image-1) in both image quality and task success rates; (II) SymbOmni effectively reduces token consumption by over 40% while maintaining competitive generation quality; and (III) SymbOmni enables effective continual learning by achieving cumulative gains across multiple online-learning benchmarks and setting a new state of the art.

深度讲解Deep dive

SymbOmni 是面向 ComfyUI 的经验学习型视觉工作流代理：不微调基础模型，而把成功与失败轨迹抽象成可检索、组合和修正的符号工作流指令，减少每次从零规划。

它解决什么问题Problem

视觉生成代理会反复从头规划，长工作流说明和试错消耗大量 token；固定工作流又难组合，自由轨迹则容易形成不可复用或污染的经验。

核心方法Core method

Symbolic Concept Box 中每个概念包含用途描述、参数化工作流指令、经验参数和历史效用分。Transduction 分解任务、按描述召回概念、按依赖过滤排序，再实例化 ComfyUI DAG；Execution 记录指令、候选工作流、输出和日志；Induction 用硬验证器与软语义验证器评估成败，把成功轨迹抽象为概念，把失败轨迹转成语言损失和符号梯度，再通过 replay 执行 add、update 或 delete。

怎么工作How it works

  1. 把请求分解成有依赖的视觉子任务。
  2. 从 Concept Box 检索并组合工作流指令。
  3. 实例化并执行 ComfyUI 节点图。
  4. 双验证器检查语法执行和语义结果。
  5. 抽象成功经验或回放失败轨迹以更新概念记忆。

论文报告了什么Reported findings

  • ComfyBench Pass/Resolve 为 100%/86.0%，复现的 ComfyMind 为 100%/73.0%；接入 Nano Banana 后 Resolve 为 91.0% 对 84.0%。
  • ReasonEdit 总分为 9.190，ComfyMind 为 8.135；GenEval Overall 为 0.98，ComfyMind 为 0.90，GPT-Image-1 为 0.84。
  • ReasonEdit 每例总 token 从 21727.1 降至 14361.4，下降 33.9%；输出 token 下降 40.1%，API 请求从 9.85 降至 7.25。
  • Offline Complex 的 30 个样本中，无工作流说明时 Resolve 为 70.0%，ComfyMind 为 66.7%，平均尝试为 1.433 对 2.000。
  • 从 147 个分布外工作流建库后，ComfyBench Overall/Complex/Creative Resolve 为 75.0%/66.7%/52.5%，对照为 67.0%/55.0%/42.5%。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：Concept Box 可缓存 StreamingModelHarness 在 endpoint 后的常见工具计划，降低重复规划 token；它不是流式感知技术。
  • 编辑判断：晚注入工具可触发工作流重选与经验更新，但论文没有生成中途插入工具或处理用户打断。
  • 编辑判断：方法没有语音输出和同步听说；Harness 的外挂 TTS 与端点后生成仍然不是原生全双工。

边界与局限Limits

  • 它主要是代理和工作流层，质量依赖 Gemini、ComfyUI 及外部生成模型，不能全部归因于独立模型能力。
  • 论文所称 token 下降超过 40%只适用于输出 token，总 token 实际下降 33.9%。
  • 多工具、多次调用代理与单次端到端模型的计算预算并不对齐。
  • 持续学习主要由 LLM 判断和记忆重写驱动，核心离线实验只有 30 个 Complex 样本。

代码与模型开放情况Code and model availability

部分开放Partial   主代理、记忆、ComfyUI 工具、原子工作流、评测 runner 和插件以 MIT 发布；没有专属权重。仓库未附完整 benchmark 输入或论文运行产物，外部模型权重、ComfyUI 工作流和基准许可证不由 MIT 覆盖。
