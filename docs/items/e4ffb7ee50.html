Cognitive-structured Multimodal Agent for Multimodal Understanding, Generation, and Editing

论文Paper · arxiv · 2026-07-09 · ◈ 14
摘要Summary
CMA 把历史图像写入带缩略图和语义元数据的外部情景记忆，每轮只取回相关图像，再由控制器选择理解、生成、编辑或合成工具。该结构适合 StreamingModelHarness 在流式输入期异步积累视觉事件、endpoint 后执行晚注入工具，但当前官方仓库尚无实现。 Recent unified multimodal models show a single architecture can jointly perform vision/language understanding and image generation/editing. However, they repeatedly feed all historical visual and textual inputs into a shared context window, limiting long-horizon multimodal dialogue due to visual token explosion and unreliable cross-turn referencing. We propose a Cognitive-structured Multimodal Agent that externalizes visual information into an Episodic Visual Memory and selectively reactivates relevant episodes during reasoning. The agent consists of a Perceptual Abstraction Engine for structured visual abstraction, a Cognitive Retrieval Engine for cross-turn memory retrieval, and a Multimodal Executive Controller for autonomous task inference and action planning. To address the lack of turn-level retrieval supervision in existing datasets, we develop a Unified Scenario Engine that programmatically generates structured multi-turn conversations with fine-grained retrieval annotations, enabling reinforcement learning to optimize abstraction and retrieval policies. We also construct a long-horizon visual-dialogue benchmark stratified by difficulty to evaluate episodic visual recall. Our 8B agent achieves 91.4% retrieval accuracy over 20-turn sessions, surpassing 32B baselines by +8.2% while nearly halving per-turn inference time (23.1s -> 12.7s). We further present the Cognitive-structured Multimodal Agent Harness (CMA-Harness), a tool-augmented deployment of the same cognitive structure integrating persistent multimodal memory, web access, image generation/editing/composition tools, and OpenAI-compatible serving. Structured memory and modular decision-making offer a more scalable, efficient paradigm for long-horizon multimodal agents than monolithic parameter scaling. Code: https://github.com/caseclose/cma-harness ; Project page: https://caseclose.github.io/cma-harness/

深度讲解Deep dive

CMA 把历史图像移出不断增长的上下文，写入带缩略图和语义元数据的情景视觉记忆；每轮只取回相关图像，再由控制器决定理解、生成、编辑或合成，重点是长程视觉引用和工具编排。

它解决什么问题Problem

全量重放历史图像会造成视觉 token 爆炸、无关图像干扰和跨轮指代失效；现有多轮数据又缺少“本轮应检索哪些历史图像”的监督。

核心方法Core method

Perceptual Abstraction Engine 把图像写成标签、详细描述与缩略图，外部 Episodic Visual Memory 持久化事件。Cognitive Retrieval Engine 同时读取查询、文本历史、候选缩略图和元数据，输出相关索引或空集；先做精确检索集 SFT，再以难度加权 Jaccard 奖励优化检索，并冻结检索器优化抽象器。Multimodal Executive Controller 识别 generation、editing、composition、understanding 或 pure-chat，再调用相应 Qwen 图像执行器并把产物写回记忆。

怎么工作How it works

  1. PAE 抽象新图像并写入外部视觉事件记忆。
  2. CoRE 根据当前查询选择最小相关历史图像集。
  3. MEC 判断任务类型并组合文本、记忆和图像上下文。
  4. 调用理解或图像生成、编辑、合成工具，再把产物写回记忆。

论文报告了什么Reported findings

  • M2CA-Bench 英文 Full/Hard 检索准确率为 91.4%/82.0%，最强 32B Multi-Agent 基线为 83.2%/72.1%。
  • 英文 Hard 上，分阶段训练将准确率从 63.6% 提升到 CoRE-SFT 的 70.9%、CoRE-RL 的 77.4% 和 PAE-RL 的 82.0%。
  • Gemini-3-Pro 质量分中英文 Overall 为 8.49/8.53，对照为 8.24/7.91；英文 Edit 7.31 低于对照的 7.49。
  • 可核验的 32B 配置中，PAE+CoRE 的运行时间为 12.7 秒，对 All-Context 的 23.1 秒；质量分为 8.77 对 7.93。
  • Hard 检索中，纯文本 MemoryLLM-style 和 ReasoningBank-style 仅为 24.4%/39.0%，带缩略图的 EVM 为 82.0%。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：可在 StreamingModelHarness 流式输入期间异步构建视觉记忆，endpoint 后只激活相关事件，控制生成上下文成本。
  • 编辑判断：MEC 的工具结果回写循环适合晚注入工具，但论文没有处理中途语音打断、边听边生成或生成期间重新规划。
  • 编辑判断：论文只验证文本/图像，没有流式语音解码、turn-taking 或音频输出；外挂 TTS 不会因此变成原生全双工。

边界与局限Limits

  • M2CA-Bench 只有 2000 个合成轮次，用户、候选回复和评分均大量依赖模型。
  • 摘要把 12.7 秒与 8B agent 并列，但可审计表格的计时行实际使用 Qwen3VL-32B。
  • 三个专门 VLM 加图像生成器的总调用量、显存和硬件未完整披露，不能把“8B 胜 32B”解释为系统总成本更低。
  • 仅覆盖文本和图像，不支持原生音频或视频流。
