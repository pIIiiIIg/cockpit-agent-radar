VetClaw: An Edge-Cloud Multimodal Agentic System for Veterinary Disease Screening

论文Paper · arxiv · 2026-07-28 · ◈ 11
摘要Summary
VetClaw 展示了 Raspberry Pi 摄像采集、OpenClaw 交互、LangGraph 安全编排和云端 VLM 分类组成的兽医早筛原型。实验说明症状文本远比单张图片更有帮助，但部分文本结果异常接近满分、数据版本和症状构造不透明，尚不能视为临床有效性证据。对 StreamingModelHarness 的启发主要是提交后云端推理、失败处理和人工升级。 We present VetClaw, an edge-cloud multimodal agentic system for early veterinary disease screening. VetClaw uses a camera module as an edge sensing device and sends captured images, together with optional symptom descriptions, to a server-hosted vision-language model for zero-shot disease classification. The system separates agent interaction from workflow orchestration: OpenClaw provides scheduling, tool access, user interaction, and notification services on the edge device, while LangGraph manages the stateful screening workflow, including input validation, image transmission, model invocation, safety checks, conditional routing, failure handling, and structured logging. This design moves beyond static image classification by enabling the system to collect visual evidence, invoke external models, apply deterministic safety rules, and generate diagnostic-support alerts. Results show that image-only VLM prediction remains limited, whereas symptom-guided and multimodal inputs improve zero-shot classification performance. Thus, VetClaw transforms a static prediction model into a coordinated, safety-aware system that can use tools, manage workflows, handle failures, and escalate uncertain cases.

深度讲解Deep dive

VetClaw 是由 Raspberry Pi 采集、OpenClaw 交互调度、LangGraph 安全编排和云端 VLM 分类组成的兽医疾病早筛原型。

它解决什么问题Problem

单张动物图片缺少物种、行为和症状上下文，大型 VLM 又不适合直接跑在边缘设备；完整系统还必须处理输入校验、失败重试、安全规则和人工升级。

核心方法Core method

OpenClaw 负责定时、摄像头和通知，LangGraph 维护状态、条件分支、重试与日志；边缘端把图片和可选症状文本送到 FastAPI/Ollama 托管的 Qwen3-VL-32B 或 InternVL3-38B，输出仅作为早筛警报。

怎么工作How it works

  1. 边缘端定时采集图片并检查文件、清晰度、亮度与格式。
  2. 图片和症状文本上传到云端 VLM 做零样本分类。
  3. LangGraph 校验类别并应用低置信度、冲突、紧急症状和 API 错误规则。
  4. 通过审查的结果生成辅助提醒，风险案例要求补充信息或转人工。
  5. 记录图片引用、模型回复、规则结果和错误。

论文报告了什么Reported findings

  • Dogs Skin Disease 上，Qwen 的 image-only 准确率/F1 为 33.26%/0.31，text+image 为 72.17%/0.69。
  • InternVL 在 Dogs 上 text-only 达到 100%，高于 text+image 的 94.34%；Pet Disease 上 Qwen 的 text-only 86.90% 也高于 text+image 84.02%。
  • 论文只给出一个延迟样例：采集 2820.47ms、上传 1977.86ms、Qwen 响应 925.3ms，没有端到端分布或方差。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：边缘缓存、endpoint/commit 后云端推理、确定性校验、重试和人工升级与 Harness 的现有编排方式相符。
  • 编辑判断：论文没有语音输入、打断或 TTS 实验，也没有证明代理编排优于普通 API 管线，不能视为模型原生全双工方案。

边界与局限Limits

  • 仅使用两套小型图片数据做零样本提示，缺少真实兽医多模态数据和兽医专家验证。
  • 症状文本构造没有充分说明，Dogs text-only 的满分结果提示标签描述泄漏或任务过易。
  • 论文所述 Pet Disease 的 1736 张/22 类与当前数据页的 5000 余张/27 类不一致，也未固定模型 revision、量化和提示版本。
