SimpleSearch-VL: A Simple Recipe for Multimodal Agentic Deep Search

论文Paper · arxiv · 2026-06-30 · ◈ 11
摘要Summary
SimpleSearch-VL 通过 FAR rollout 分配、带缩略图核验的区域图片搜索和策略模型自摘要，构建较轻量的多模态深度搜索代理。论文报告 8B/30B-A3B 相对对应基线平均提升 15.8/16.0 个百分点，但官方仓库仍只是预览，代码、权重和数据均未发布。 We present SimpleSearch-VL, an efficient, reliable, and practical framework for multimodal agentic search. Its core idea is to improve the agent's own search-and-verification process rather than scaling data, tools, or auxiliary model components. For efficiency, Factorized Adaptive Rollout (FAR) improves sampling efficiency by forming more informative training groups while using redundant samples to mitigate long-tail latency and expose hard samples. For reliability, SimpleSearch-VL performs evidence-verified reasoning, explicitly using chain-of-thought verification to assess the relevance of retrieved visual and textual cues to the original context. For practicality, SimpleSearch-VL keeps a lightweight tool interface and performs webpage self-summary within the agent, requiring no additional external dependencies. With only 5K supervised tool-interleaved trajectories and 2K RL data, SimpleSearch-VL improves Qwen3-VL agentic baselines by 15.8 and 16.0 average points for the 8B and 30B-A3B variants, respectively. The SimpleSearch-VL-30B-A3B model further achieves performance competitive with agentic Gemini-3-Pro.

深度讲解Deep dive

SimpleSearch-VL 用自适应 rollout 分配、可核验的区域反向图片搜索和策略模型自摘要，后训练一个轻量多模态深度搜索代理。

它解决什么问题Problem

多模态搜索训练受到工具 rollout 长尾等待、反向图片搜索的伪匹配、工具过度耦合和额外网页摘要模型等效率与可靠性问题影响。

核心方法Core method

FAR 把预算分为 prompt 扩展和 rollout 分配：仍全错的组获得更多采样，出现正确样本后屏蔽冗余槽位。运行时将 text_search、image_search、visit 解耦，图片搜索返回缩略图、标题和 URL 供模型核验，网页摘要由同一策略模型完成。

怎么工作How it works

  1. 模型每轮只调用文本搜索、区域图片搜索、网页访问之一或提交答案。
  2. 图片搜索返回缩略图和来源，模型先比对目标区域再决定是否信任。
  3. 网页内容规范化后由策略模型按当前问题自行摘要。
  4. 用证据感知工具轨迹做 SFT，再以答案和格式奖励做 RL。
  5. FAR 根据训练组是否出现正样本动态分配额外 rollout。

论文报告了什么Reported findings

  • 8B 与 30B-A3B 在六个基准上相对对应 Qwen3-VL agentic baseline 的均值分别提高 15.8 和 16.0 个百分点。
  • FAR(2×,4–8) 每步 187 秒、平均 62.8；标准采样为 192 秒、56.6，时间相近而平均高 6.2 分。
  • 策略模型自摘要用时 358 秒、平均 69.7；外部 8B 摘要器为 501 秒、67.9。
  • 实际训练使用 5193 条 SFT 轨迹和 1995 个 RL prompt；8B 在 8 张 H200 上约需 2 小时 SFT 加 16 小时 RL。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：解耦的文本、区域图片和网页工具适合 Harness 的晚注入接口，缩略图核验可降低搜索结果看似相关却证据不匹配的问题。
  • 编辑判断：FAR 是后训练技术，自摘要还会占用生成时间；论文没有流式音频、打断或 TTS，不能直接改善 endpoint 前延迟。

边界与局限Limits

  • 多数消融只用 914 个训练样本，除 MMSearch 外每个评测集仅抽样 100 条，且没有误差条或多随机种子。
  • 数据由大型 Qwen 生成并由 Gemini 重写，奖励又依赖 Qwen judge，存在教师和评审偏差。
  • 运行依赖 Serper、JINA Reader、对象存储和随时间变化的网页内容；所谓 minimal dependencies 仅指不另部署摘要模型。
