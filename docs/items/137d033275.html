Sympatheia: Emotionally Adaptive Voice Assistant with Continuous Affect Conditioning

论文Paper · arxiv · 2026-05-30 · ◈ 16
摘要Summary
Sympatheia 在 GLM-4-Voice-9B 上用连续 valence–arousal 条件控制内容与原生语音，显式 VA 将 Neutral 分数从 1.883 提升到 4.368。Harness 可在首 token 前注入 VA，但外挂 TTS 也必须支持相同风格控制，否则只能保留内容层适配，不能外推论文的韵律收益。 Empathetic spoken dialogue systems must infer a user's emotional state to respond appropriately, yet everyday speech often carries weak, neutral, or ambiguous affective cues. To address this, we introduce Sympatheia, a speech-to-speech dialogue framework conditioned on affect inferred from the user's speech and, when available, explicit affect specifications provided as a continuous valence--arousal (VA) control sign

深度讲解Deep dive

Sympatheia 在 GLM-4-Voice-9B 上用 LoRA 学习连续 valence–arousal 条件，使回答内容和模型原生语音随用户情绪变化，并统一接收面部、生理或文本情绪模块输出的 VA。

它解决什么问题Problem

日常语音的情绪线索常弱、模糊或混合，离散情绪标签难表达强度、连续变化和个体差异。

核心方法Core method

系统将可选的 valence/arousal 数值写入 system prompt；没有显式 VA 时从用户语音推断。GLM-4-Voice 生成文本和语音 token，streaming flow-matching decoder 还原波形；Sympatheia-18k 以 12 个情绪锚点训练语义与声学适配。

怎么工作How it works

  1. WhisperVQ 将用户音频编码为 12.5Hz 单码本 speech token。
  2. 可选面部、EEG/ECG/GSR 或文本模块输出类别分布并映射为连续 VA。
  3. 把 VA 写入 system prompt，LoRA 适配的 GLM-4-Voice 生成文本与语音 token。
  4. 流匹配解码器生成波形；没有外部 VA 时依赖输入语音自身的情绪线索。

论文报告了什么Reported findings

  • Table 1 中 Sympatheia 的 Neutral/Emotional/VoiceBench/人工 Emotion MOS 为 4.37/4.74/4.22/3.86，Qwen3-Omni 为 2.59/4.69/1.88/3.32。
  • Appendix Table 11 中显式 VA 将 Neutral 从 1.883 提升到 4.368，VoiceBench 从 1.690 提升到 4.224。
  • Table 3 中离线面部线索为 3.64、无 cue 为 1.92；现场面部为 3.39/1.98，文本描述为 3.57/1.63。
  • VA 噪声 σ 从 0 增至 0.1/0.2/0.3/0.5 时，情绪匹配分从 4.32 降至 3.79/3.59/3.51/3.30。
对 StreamingModelHarness 的帮助（编辑判断）Fit for StreamingModelHarness (editorial analysis)
  • 编辑判断：Harness 可在 endpoint 后把 VA 注入 system prompt，但论文的韵律增益来自原生语音 decoder；外挂 TTS 只有同时支持 VA/style 才能保留声学效果。
  • 编辑判断：若把情绪传感器作为晚注入工具，应在首 token 前完成；该方案仍是 endpoint 后条件生成，不应称为模型级全双工。

边界与局限Limits

  • 合成数据无法充分覆盖真实口误、说话人差异和长程情绪动态。
  • 单个 VA 点不能完整表示混合、快速变化及受文化/个体影响的情绪。
  • 评测高度依赖自动音频 LLM judge，数据、TTS 和 judge 同属 Qwen3 系列，可能存在模型家族偏差。
  • 上游情绪识别尤其是生理信号容易出错，并带来隐私、同意和公平风险。
