# 每日调研日报｜2026-08-10

今日结论：无论文级重大新增。Radar 新增中只有三个官方项目仓库值得持续关注；第三方模型
镜像/量化不算新模型，固定返回 95ms 的 GenPark 示例客户端不算全双工实测。

- 打断与续说：jax-realtime（当前缺少“停顿后续说”和“听见回复后打断”的分流评测；用
  700ms 首音频前合并窗口、实际播放门控的回声底噪和可取消 TTS 状态机；可以先加入
  续说/打断/工具播报/自回声四类离线回放）
- 语义判停：Silero VAD + continuation-merge（当前仅靠静音判停会把思考停顿切断；作者自测
  显示预判窗口无稳定收益，改为 endpoint 后取消未听见回复并合并转写；可以验证中文长停顿，
  但不能直接沿用英语参数）
- TTS：标点分块与单时钟取消（当前首音频约 3 秒且外挂 TTS 是主瓶颈；jax-realtime 证明
  词边界早切会产生假句末韵律，首声数字和听感可能相反；可以同时测首音频、残音、句间空洞
  和盲听自然度）
- KV cache 与实时服务：固定 shape/历史窗（当前 110ms/token 根因是 HF MoE 同步，不是
  DynamicCache；jax-realtime 的 bucket/warmup 只适合借鉴阶段埋点；可以先消除同步，再单独
  验证 shape 抖动，禁止混称“KV 修复”）
- 多模态座舱：AoiVR（当前视觉、系统音频与车控主通道需要背压隔离；原生 C++ agent、Unity
  UI、流式 TTS 和带时间戳 C ABI 可作架构参考；可以回放过期视觉结果和动作通道抢占，但其
  没有多乘员、空间听觉或打断指标）
- 实时服务：ShipVoice Lite（当前缺 WebRTC/SIP 断连、worker 排空和取消语义基线；模板把
  worker、token 服务和前端拆开；可以做故障注入参考，但默认 backend 无认证且 signing
  secret 未加密，不能直接进入车控链路）
- AEC/降噪、空间听觉、多乘员、原生全双工模型：无可信新增（继续跟踪论文正文、作者项目页
  和官方代码/模型页；在出现双讲、说话人/座位真值或可复现流式指标前不启动新实验）

今日建议：P0 先补交互事件账本和可听回环；P1 再做 TTS 多目标对照与多模态背压；不启动
新的 H20 候选，且不重跑前一日已离线拒绝的 Top-2 verifier。
