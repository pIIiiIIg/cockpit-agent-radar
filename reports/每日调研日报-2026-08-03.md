## 问题驱动摘要

- **长会话能力下降：M3-DuplexBench + Voice Memory / AdaMM / ReflectWorld-MM**
  固定完整历史量化KV逐轮退化，再把ASR规则、实体和事件迁出模型KV；目标是8轮后任务成功率下降不超过3个百分点。

- **轮替和打断：M3-DuplexBench**
  增加SHIFT、PAUSE、BACKCHANNEL和BARGE_IN真实回放。它负责评测，不能替代独立语义判停器。

- **真实双讲鲁棒性：faster-enhancer.c**
  放在AEC/LMPAN之后做常开因果NS，按clean、噪声和回声分桶验证；新增前端P95目标不超过30ms。

- **视觉在线化：Mage-VL**
  将视频I/P帧和运动残差作为“视觉VAD”，只在乘员动作或场景变化时写入视觉KV；目标是视觉token下降至少70%且不影响音频deadline。

- **车控错误持续修复：Voice Memory + ARDena**
  用保留集门控的可审计规则修复同音词和近义工具错误，把驾驶/驻车/儿童在车等动态约束放入独立Policy层；最终执行仍经过typed call安全门。

- **具身Action：iFLYTEK-Embodied-Omni**
  借鉴“规划脑+动作小脑”分层，用确定性执行器落实座舱动作，不直接采用机器人动作模型。

- **音视频联合数据：OmniVideo-100K**
  借鉴实体锚定和跨段证据链构造座舱音视频评测，避免视觉与语音只做各自理解。
